# CAP战术模板集成需求文档

## 1. 项目背景

### 1.1 原有系统
- **位置**: `scripts/tacticalProject/run_simulation.py`
- **功能**: 成熟的2v2超视距战术模板系统
- **战术**: 5种战术模板（拖拽射击、钳形攻势、高低攻击、前后攻击、并排返航）
- **状态**: 经过充分测试，战术执行稳定

### 1.2 新系统
- **位置**: `scripts/tacticalProject/cap/`
- **功能**: 4v4 CAP巡逻任务
- **新特性**: 协同探测、接力制导、预警机支持
- **问题**: 战术模板集成不完整，导致交战效果差

### 1.3 集成目标
将原有2v2战术模板系统完整嵌入到CAP项目中，实现：
- 协同探测阶段使用CAP新功能
- 交战阶段使用原有成熟战术模板
- 4v4拆分成2个独立的2v2编队

## 2. 核心问题

### 2.1 EVADE状态过早触发 ⚠️ 高优先级

**问题描述**:
```
[10:36:31] [CAP] [CAP状态] ENGAGE -> EVADE
[10:36:31] [状态] [254s] EVADE | 战术:drag_shoot | 距离:145km
```

**现象**:
- 一检测到导弹就立即进入EVADE状态
- 持续执行三九机动规避
- 无法正常交战

**根本原因**:
`cap_state_machine.py`中`_should_evade()`条件过于宽松：
```python
def _should_evade(self, ctx: StateContext) -> bool:
    if ctx.is_missile_incoming:  # ❌ 任何导弹都触发规避
        return True
    if ctx.min_threat_distance < self.ranges.MAR:  # ❌ 40km就规避
        return True
```

**期望行为**:
- 参考`run_simulation.py`的逻辑
- 只有在真正危险时才规避（如导弹进入末段、距离<20km等）
- 正常交战距离（40-80km）不应触发规避

### 2.2 距离计算不一致 ⚠️ 高优先级

**问题描述**:
- Tacview显示: 敌我距离约50海里（92.6km）
- 日志显示: 威胁距离145km
- 时间点: 4分17秒（254秒）

**可能原因**:
1. 使用了不同的距离计算方法
2. 混淆了雷达探测距离和实际物理距离
3. 坐标系转换错误

**需要验证**:
- 距离计算公式是否正确
- 是否使用了正确的坐标系
- 雷达探测距离 vs 实际距离

### 2.3 4v4编队拆分缺失 ⚠️ 中优先级

**问题描述**:
- 当前CAP系统将4架飞机作为一个整体
- 没有实现2个2v2编队的独立战术执行

**期望行为**:
1. 协同探测阶段: 4架飞机协同工作
2. 交战阶段: 拆分成2个2v2编队
   - 编队1: A0100 + A0200 vs B0100 + B0200
   - 编队2: A0300 + A0400 vs B0300 + B0400
3. 每个编队独立执行战术模板

### 2.4 战术模板集成不完整 ⚠️ 高优先级

**问题描述**:
- CAP系统没有完整集成原有5种战术模板
- 战术选择逻辑不完整
- 战术执行流程与原系统不一致

**需要集成的战术**:
1. DRAG_SHOOT - 拖拽射击
2. PINCER_ATTACK - 钳形攻势
3. HIGH_LOW_ATTACK - 高低攻击
4. FRONT_BACK - 前后攻击
5. SIDE_BY_SIDE - 并排返航

# F16航向控制修复规范

## 问题描述
敌方F16飞机从初始180°航向严重偏离到158-165°，偏差达15-20°，且误差随时间累积。

## 根本原因分析
1. **控制冲突**：在`get_action()`中计算PID航向命令，但在`_lowlevel_control()`中又尝试覆盖方向舵输出，导致两层控制相互干扰
2. **模型特性**：F16底层模型通过强化学习训练，设计用于跟随高层航向命令，不适合底层舵面直接控制
3. **增益不足**：方向舵修正增益0.05太弱，无法有效纠正大角度偏差

## 解决方案

### 方案A：纯高层命令控制（推荐）
**原理**：完全依赖底层模型的航向跟随能力，通过优化高层命令实现精确控制

**实现**：
1. 移除`_lowlevel_control()`中的方向舵覆盖代码
2. 在`get_action()`中使用增强PID控制器
3. 增加比例增益Kp（5.0→10.0）和积分增益Ki（0.1→0.3）
4. 添加微分项Kd=0.5抑制振荡
5. 使用更精细的航向命令映射

**优点**：
- 不破坏底层模型的控制逻辑
- 利用模型已有的航向跟随能力
- 控制信号单一，无冲突

**缺点**：
- 依赖底层模型质量
- 可能存在稳态误差

### 方案B：混合控制（备选）
**原理**：高层命令为主，底层舵面微调为辅

**实现**：
1. 保持高层PID命令
2. 仅在误差>5°时进行小幅度方向舵修正（增益0.02）
3. 避免大幅度覆盖底层输出

## 验收标准
1. F16在1500步（5分钟）仿真中，航向偏差<3°
2. 无明显振荡（连续偏差变化<1°/步）
3. 稳态误差<1°
4. 代码简洁，无冗余逻辑

## 实施步骤
1. 清理`_lowlevel_control()`中的方向舵覆盖代码
2. 在`get_action()`中实现完整PID控制器（P+I+D）
3. 优化航向命令映射逻辑
4. 运行`test_f16_long.py`验证效果
5. 如方案A不满足要求，实施方案B

================================================================================
                     敌方AI下降异常诊断 - 一键运行
================================================================================

你只需要运行以下命令之一即可：

【方式1】推荐 - 直接运行（最简单）
───────────────────────────────────

cd D:\Pycharm\LAG\scripts\tacticalProject
python run_with_debug.py

然后等待仿真完成即可。完成后会显示日志文件位置。


【方式2】双击批处理文件
──────────────────────

双击: D:\Pycharm\LAG\scripts\tacticalProject\enable_descent_debug.bat

这会启动仿真，然后自动显示结果。


【方式3】手动运行（如果你想要更多控制）
────────────────────────────────────────

cd D:\Pycharm\LAG\scripts\tacticalProject

# 设置环境变量
set ENEMY_DESCENT_DEBUG=1
set CAP_ROOTCAUSE_TRACE=1

# 运行仿真
python run_cap_simulation_native.py

================================================================================

仿真完成后，查看日志：

  type cap_results\descent_debug.log

================================================================================

日志中会显示下降事件，例如：

  [决策追踪] T=476.0s | B0200 @14458.7m
  selected_action=DIVE_ESCAPE
  is_descent=True
  descent_magnitude=300.0m

这就是你要的信息：
  ✓ 什么时候: T=476s
  ✓ 进入哪个函数: DIVE_ESCAPE
  ✓ 下降了多少: 300m

================================================================================

搜索特定智能体的下降：

  Select-String "B0200" cap_results\descent_debug.log
  Select-String "is_descent=True" cap_results\descent_debug.log

================================================================================

就这样！不用复杂的步骤，一个命令搞定！

  python run_with_debug.py

================================================================================

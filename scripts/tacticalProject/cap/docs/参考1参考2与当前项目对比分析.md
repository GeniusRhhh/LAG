# 参考1、参考2与当前协同探测算法设计报告的对比分析

本文档针对 **协同探测算法设计报告.md**，结合 **协同探测参考1.md**（学位论文）、**协同探测参考2.md**（期刊论文）进行任务场景与实现算法的对比分析，明确三者的异同及当前项目的定位。

---

## 一、参考1：协同探测参考1.md（学位论文）

### 1.1 文献信息与定位

- **题目**：多无人机协同空战分布式任务规划方法研究  
- **类型**：沈阳航空航天大学硕士学位论文  
- **关键词**：分布式、协同空战、任务规划、协同探测、ACBAA、DIAA  

### 1.2 任务场景

| 维度 | 内容 |
|------|------|
| **平台** | 我方 $n$ 架无人机（UCAV），敌方 $m$ 架目标；**无预警机**，各机自带雷达 |
| **探测阶段** | 多架无人机对**某一区域**进行探测，发现目标后建立目标状态信息（坐标、速度、性质、时间戳、目标数量、目标标号），通过通信**与友机对比、去重、重编号**，直到**所有无人机目标信息一致** |
| **决策阶段** | 在**探测完成后**，基于**空战态势**（态势优势、态势威胁）做**目标分配**：谁攻击哪个目标；必要时“邀请”友机协同攻击 |
| **传感器** | **同构**：每架无人机一部机载雷达，探测范围 $r_i$（如 200 km），无异构融合 |

### 1.3 协同探测部分（第3章）在解决什么问题

- **问题**：多机各自探测到的目标列表不一致（同一目标被不同飞机标成不同编号，或有人漏检），需要形成**编队内一致的目标表**。  
- **一致性定义**：  
  - 位置、速度在允许误差内（$\|K_i(t)-K_j(t)\|<\varepsilon$，$|V_i-V_j|<\varepsilon_v$）；  
  - 目标性质、时间戳、目标编号、每机探测到的目标数量**必须相同**。  
- **方法**：基于**一致性原理**的分布式协同探测——  
  - 探测到目标的无人机把该目标状态发给**邻接友机**；  
  - 友机用**位置+速度门限**判断是否为同一目标；  
  - 同一目标则按时间戳或优先级保留一份、统一编号；不同目标则加入本地列表并重排序；  
  - 通过通信图 $G(t)$、拉普拉斯矩阵等，在无向连通图上迭代直到状态一致。  

**结论**：参考1的“协同探测”= **多同构平台对同一空域探测后的目标列表融合与一致化**，为后续**目标分配（谁打谁）**提供输入；**不涉及路径规划、不涉及预警机、不涉及雷达波束/扫描分配**。

### 1.4 实现算法概览

| 模块 | 算法 | 作用 |
|------|------|------|
| **协同探测** | 基于一致性的分布式协同探测 | 目标信息在邻接节点间交换，按位置/速度门限判同目标、重编号、重排序，直至全编队目标信息一致 |
| **空战决策（第4章）** | **DIAA**（分布式邀请拍卖） | 按态势优势分配目标；冲突时按收益竞标；能力不足时“邀请”友机协同攻击，接收方按收益/时间戳决定是否接受 |
| **模糊态势（第5章）** | **ACBAA**（异步一致性拍卖） | 拍卖阶段：每机对未分配目标算收益，竞标收益最高者；一致性阶段：邻接节点交换竞标信息，按“一致性无冲突法则”更新/保持/重置，解决分配冲突；支持协同变量（两枚弹协同打一发） |

## 二、参考2：协同探测参考2.md（期刊论文）

### 2.1 文献信息与定位

- **题目**：多机协同对空目标探测与攻击任务的最优分配  
- **类型**：期刊论文（火力与指挥控制，2011）  
- **关键词**：任务分配、协同空战、目标探测、目标攻击、粒子群优化算法  

### 2.2 任务场景

| 维度 | 内容 |
|------|------|
| **平台** | 我方 $M$ 架飞机，敌方 $N$ 架目标；**无预警机**，每机自带雷达与导弹 |
| **核心需求** | 协同制导：既要**谁探测哪个目标**（提供目标指示），又要**谁对哪个目标发射导弹**；探测任务与攻击任务**联合分配** |
| **态势描述** | “双方态势图”：F 为我机，T 为目标，$\varphi$ 为目标相对我方的方位角，$q$ 为目标进入角；据此建**探测优势**与**攻击优势** |
| **传感器** | **同构/近同构**：每机有雷达（$D_{DET}$、$C_R$）和导弹（$D_{ATCmax/min}$、$C_M$） |

### 2.3 探测与攻击在解决什么问题

- **探测任务分配**：  
  - 建立**探测优势函数** $T_{DET}$（角度优势 $T_{det\,a}$、距离优势 $T_{det\,d}$、雷达能力 $T_{det\,c}$），形成矩阵 $T_{DETmn}$。  
  - 目标：$\max \sum_{m,n} T_{DETmn} x_{mn}$，约束为每机最多探测 $MAXDET_m$ 个目标、每目标最多被 1 架机探测。  
- **攻击任务分配**：  
  - 建立**攻击优势函数** $T_{ATC}$（角度、距离、速度、导弹能力），形成 $T_{ATCmn}$。  
  - 目标：$\max \sum_{m,n} T_{ATCmn} y_{mn}$，约束为每机最多攻击 $MAXATC_m$ 个目标、每目标最多被 1 架机攻击。  
- **联合模型**：  
  - 多目标转为单目标：$J = \max \big( w_{det} \sum T_{DETmn}x_{mn} + w_{atc} \sum T_{ATCmn} y_{mn} \big)$，约束同时包含探测与攻击的 0-1 变量。  

**结论**：参考2的“协同探测”= **在多机多目标下，为每个目标指派“由哪一架飞机负责探测”**，与“由哪一架飞机负责攻击”一起构成**静态任务分配**；**不涉及时间轴上的路径规划、不涉及预警机、不涉及波束扫描与模式切换**。

### 2.4 实现算法概览

| 模块 | 算法 | 作用 |
|------|------|------|
| **建模** | 探测优势函数 + 攻击优势函数 | 由态势（方位角、进入角、距离、速度）与装备性能（雷达 $C_R$、导弹 $C_M$）得到 $T_{DET}$、$T_{ATC}$ |
| **求解** | **遗传操作离散粒子群优化（PSO）** | 编码：长度为 $2N$ 的向量（前 $N$ 维为每目标由谁探测，后 $N$ 维为每目标由谁攻击）；用交叉、变异、选择等遗传操作更新粒子，在离散解空间搜索使 $J$ 最大的 $(x,y)$ |

## 三、当前项目：协同探测算法设计报告.md

### 3.1 任务场景（简要）

| 维度 | 内容 |
|------|------|
| **平台** | 我方 4 架战斗机（双机对编队），**预警机 + 战斗机火控雷达**两类传感器 |
| **阶段划分** | **主阶段（0–200 km）**：从预警机发现目标（约 300–400 km）到进入火控雷达 200 km 门限——核心是**编队拦截路径规划**（航向、速度、编队协调）；**次阶段（≤200 km）**：进入门限后的**雷达扫描模式与扫描任务分配**（推磨/定向/搜索），以尽快截获并稳定跟踪 |
| **传感器** | **异构**：预警机远距、低精度（$\sigma_{awacs}$）；火控雷达近距、高精度（$\sigma_{radar}$），扫描视场/周期由体制决定 |
| **不确定性** | 敌方航向**时变、可机动**；预警机信息可能**间歇/丢失**；敌方编队分布、高度、速度多样 |

### 3.2 核心问题（与参考1、参考2的差异）

- **不是“谁探测哪个目标”的分配**：  
  - 参考1：谁探测到目标后，如何与友机**一致化目标列表**。  
  - 参考2：在给定态势下，**静态分配**“哪架机探测哪几个目标、哪架机攻击哪几个目标”。  
- **当前项目**：  
  - 探测源已定（预警机远距、火控雷达近距），问题是在**预警机引导下**如何**规划路径与雷达使用**，使编队尽快到达 200 km 内并完成截获。  
  - 因此核心是：**路径规划 + 编队协调 + 雷达扫描调度**，而不是“探测任务/攻击任务在平台间的分配”。

### 3.3 实现算法概览（与两篇参考的对应关系）

| 模块 | 当前报告算法 | 与参考1/2的对比 |
|------|--------------|-----------------|
| **状态估计** | IMM-EKF（目标运动 + 传感器观测） | 参考1/2无显式滤波；当前需处理预警机大误差与机动不确定性 |
| **信息层** | 信息可用性 $Q_{awacs}$、目标丢失判据 $target\_lost$ | 参考1有一致性误差门限；当前强调预警机质量与丢失触发搜索 |
| **估计/预测** | 编队中心 $\hat{\mathbf{p}}_{enemy}$、分布范围 $\sigma_{enemy}$、机动不确定性 $\sigma_{man}(t)$、置信域 $R_{target}(t)$ | 参考1/2无“置信域/机动不确定性传播”；当前独有 |
| **路径与编队** | 编队级引导（算法2.6）、速度协调（算法2.7）、动态路径调整（算法2.10） | 参考1/2无路径规划与编队协调；当前核心 |
| **雷达资源** | 探测模式决策（效用 $U(mode)$）、推磨/定向/智能搜索分配、扫描范围计算 | 参考2是“谁探测谁”；当前是“用什么模式、扫哪块空域”，不分配“哪架机对哪目标负责探测” |
| **任务分配类算法** | 无 ACBAA/DIAA 式“平台–目标”拍卖与一致性 | 参考1有 ACBAA/DIAA；当前无此类目标分配，因问题不同 |

## 四、三者对比小结

### 4.1 任务场景对比

| 对比项 | 参考1（学位论文） | 参考2（期刊论文） | 当前报告 |
|--------|--------------------|--------------------|----------|
| **传感器结构** | 同构（多机各自雷达） | 同构/近同构（每机雷达+导弹） | **异构**（预警机 + 火控雷达） |
| **是否有预警机** | 无 | 无 | **有**，且是远距信息源 |
| **“协同探测”含义** | 多机探测后**目标列表一致化** | **谁对谁探测**的静态任务分配 | **在预警引导下的路径规划 + 到位后雷达扫描调度** |
| **是否含路径规划** | 否 | 否 | **是**（0–200 km 拦截路径与编队协调） |
| **是否含攻击/制导分配** | 是（DIAA/ACBAA 分配谁打谁） | 是（探测+攻击联合分配） | 否（只到“稳定航迹”，与后续模块解耦） |
| **不确定性重点** | 探测误差、通信拓扑 | 态势参数、权重 | **预警机误差、敌方机动、信息丢失** |

### 4.2 实现算法对比

| 对比项 | 参考1 | 参考2 | 当前报告 |
|--------|--------|--------|----------|
| **协同探测核心算法** | 一致性协议（门限判同目标 + 重编号 + 通信图迭代） | 优势函数 + 整数规划/组合优化 | 信息质量与丢失判据 + 置信域 + 路径规划 + 扫描分配 |
| **任务分配类算法** | ACBAA（拍卖+一致性）、DIAA（竞标+邀请） | PSO+遗传操作求 $(x,y)$ | **无**（不做“平台–目标”分配） |
| **状态/滤波** | 无系统滤波模型 | 无 | IMM-EKF + 机动不确定性传播 |
| **优化形式** | 分布式、异步、规则+拍卖 | 集中式 PSO、单目标加权 | 分层滚动、效用/覆盖约束、离散候选+启发式 |

### 4.3 与当前实际项目的不同（可直接用于报告表述）

1. **问题类型不同**  
   - 参考1、参考2：**多平台对多目标的探测/攻击任务分配**（who detects whom / who attacks whom）。  
   - 当前项目：**预警机引导下的编队拦截路径规划 + 进入门限后的雷达扫描调度**，探测源和武器发射不在此报告的任务分配范围内。

2. **传感器与信息流不同**  
   - 参考1、参考2：平台同构，信息来自各自雷达，协同体现在“列表一致”或“任务指派”。  
   - 当前项目：预警机提供粗信息，火控雷达提供精信息，**异构融合与引导**是核心，且要考虑预警机信息丢失与敌方机动。

3. **算法形态不同**  
   - 参考1：分布式一致性 + 拍卖（ACBAA/DIAA），强调通信图与无冲突分配。  
   - 参考2：优势函数建模 + 集中式 PSO 求 0-1 分配。  
   - 当前项目：**无平台–目标分配算法**，而是**滚动路径规划 + 置信域 + 效用/覆盖约束下的扫描模式与扇区分配**，更偏“控制/调度”而非“组合任务分配”。

4. **可借鉴点**  
   - 参考1：一致性思想可用于“多机对同一目标表的理解一致”（若将来扩展多源融合与编队内共识）。  
   - 参考2：**优势函数/效用函数的建模方式**（权重、多指标综合）与当前报告中的**效用函数**写法一致。**说明**：当前报告**已经采用**效用函数形式的建模——第3.1节给出探测模式效用 $U(mode)=w_1 S_{cov}-w_2 C_{res}-w_3\mathbb{I}(target\_lost)\mathbb{I}(m\neq\text{WIDE})$ 与覆盖满足度 $S_{cov}$，与参考2中“优势函数加权”的写法同属一类（多指标加权、可优化）。区别仅在于：参考2用优势函数做**“平台–目标”任务分配**，当前报告用效用函数做**“探测模式选择”与覆盖约束**；二者都是优势/效用类函数，当前报告并非未用此类建模。

## 五、结论（供报告撰写参考）

- **参考1**：解决的是**同构多机探测后的目标信息一致化**以及**空战目标分配（谁打谁）**，算法以一致性协议和拍卖（ACBAA/DIAA）为主。  
- **参考2**：解决的是**给定态势下探测任务与攻击任务的联合最优分配**，算法以优势函数建模 + 粒子群优化为主。  
- **当前协同探测算法设计报告**：解决的是**预警机 + 火控雷达异构下的拦截路径规划与雷达扫描调度**，核心是路径与编队协调、置信域与机动不确定性、扫描模式与覆盖约束，**不包含“谁对哪一目标负责探测/攻击”的分配问题**。  

在报告中可明确写出：本研究与“多机协同探测/攻击任务分配”类文献（如参考1、参考2）的**问题边界不同**——本研究聚焦**预警引导阶段的路径与扫描调度**，任务分配类算法（ACBAA、DIAA、探测/攻击优势分配）不直接适用，但优势/效用建模思想可与本报告的效用函数与覆盖约束设计相呼应。

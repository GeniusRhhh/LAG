# PPT第六部分替换方案_按0511promote三场景

这份文件只解决一个问题：在当前已经确定“每场仿真固定 4 页”的前提下，第六部分到底该怎么设计，才能最大程度保留你原来单场景 PPT 的优点，同时与当前主文档和备注稿保持完全一致。

最终结构固定为：

- `49`：第六部分章节页
- `50-53`：场景一
- `54-57`：场景二
- `58-61`：场景三
- `62`：三场景横向对比与本章结论
- `63`：致谢

这一套结构的核心逻辑不变：

1. 每一场第一页讲全流程概况和时间线。
2. 第二页讲协同探测、协同跟踪和稳定交战就绪。
3. 第三页讲控制距离推进、模板演化和分层决策。
4. 第四页讲发射门、接力制导、战果形成和当前边界。

但当前版本相对旧版有一个关键修正：协同探测相关页面不再直接使用“激活后统计到仿真结束”的全程覆盖率，而是统一采用两层口径。

- 第一层是**严格协同探测阶段口径**：首次火控雷达激活到联队全探完成。
- 第二层是**探测-跟踪衔接口径**：首次火控雷达激活到首次稳定交战就绪。

这样处理后，PPT、主文档和备注稿三份材料的口径完全一致，也不会再把后段发射、规避、接力和残局控制错误算进协同探测算法本体。

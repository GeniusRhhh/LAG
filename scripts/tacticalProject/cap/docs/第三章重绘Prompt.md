# 第三章图形重绘独立 Prompt

以下四段 Prompt 均为独立使用版本。

使用方式：
- 每次只发送其中一段 Prompt。
- 同时上传一张现有参考图片。
- 要求绘图 AI 严格模仿你上传图片的风格，只重画当前图的内容，不依赖任何其他 Prompt。

---

## 图3.2 独立 Prompt

```text
请严格按照我这次上传的参考图片风格，重绘一张“敌方中心估计与目标区域估计示意图”。

重要要求：
1. 风格必须严格模仿我上传的参考图片，只模仿其视觉风格、排版气质、颜色组织、线条粗细、留白方式、飞机符号、半透明区域表现方式，不要照搬参考图原有内容。
2. 必须是白色背景，不能用黑底、灰底、深色底。
3. 必须是二维俯视、学术论文技术示意图风格，不能做成海报、UI界面、科幻屏幕、三维渲染、写实插画。
4. 图要以图形表达为主，文字极少，只保留必要标签。
5. 整体观感必须规整、清爽、专业、适合硕士论文正文插图。

这张图要表达的算法含义：
1. 预警机获得的敌方信息不是精确位置，而是带误差的离散观测。
2. 多个敌方观测点可以估计出一个“敌方中心估计”。
3. 在测量误差、敌方机动不确定性、信息丢失时间增长的共同作用下，围绕该中心形成一个圆形“目标区域 R_target”。
4. 这张图的重点是“散布观测 -> 中心估计 -> 目标区域膨胀”。

推荐主构图：
1. 画面主体为一个二维平面示意图，带浅色细网格，但网格要很淡，不能抢画面。
2. 主图中央偏上位置布置4个蓝色敌机示意点或蓝色敌机小图标，形成一个横向展开的敌方编队。
3. 在每个敌机附近画若干浅蓝或橙色小散点，表示预警粗测量散布。
4. 散点整体中心位置放一个深色或黑色小实心点，标注“敌方中心估计”。
5. 以该中心为圆心画一个明显的浅蓝半透明圆形区域，标注“目标区域 R_target”。
6. 目标区域半径要明显大于散点局部离散范围，直观看出它是保守包络后的搜索区域。
7. 主图下方可以极简画出4架红色我方飞机，表示我方在下方接敌，但不要喧宾夺主。

左上角辅助模块：
1. 画一架预警机小图标。
2. 从预警机朝敌方区域画出简单探测关系线或淡色探测扇面。
3. 只保留极少文字，例如“预警粗测量”。

右侧三个小机制插图：
1. 第一个小框表达“测量误差增大”：
   - 左边是散点较集中
   - 右边是散点更分散
   - 中间箭头连接
2. 第二个小框表达“机动不确定性增大”：
   - 左边是较小目标区域
   - 右边是更大的区域，体现不确定性外扩
3. 第三个小框表达“丢失时间增长”：
   - 左边区域较小
   - 右边区域更大
4. 三个小框都要极简，白底，文字很少。

文字要求：
只允许少量中文标签，例如：
- 预警粗测量
- 敌方中心估计
- 目标区域 R_target
- 测量误差
- 机动不确定性
- 丢失时间增长

禁止事项：
1. 不要写长段解释。
2. 不要放公式大段文字。
3. 不要做成复杂的流程图。
4. 不要画成多层理论分区图，不要额外引入文档里没有的新概念。

最终效果要求：
1. 一眼能看出“散点观测、中心估计、圆形目标区域”三层关系。
2. 图形表达远多于文字表达。
3. 视觉风格必须与我上传的参考图片高度一致。
4. 输出高清 PNG，适合直接插入论文正文。
```

## 图3.3 独立 Prompt

```text
请严格按照我这次上传的参考图片风格，重绘一张“编队引导几何关系示意图”。

重要要求：
1. 风格必须严格模仿我上传的参考图片，只模仿视觉风格，不复制原图内容。
2. 必须是白色背景、二维俯视、学术论文插图风格。
3. 图形为主，文字极少，不能画成说明书式的大段文字图。
4. 线条、箭头、飞机轮廓、半透明区域、网格留白，都必须尽量贴近我上传图片的风格。

这张图要表达的核心含义：
1. 我方4机并不是一开始就完全对称地直接飞向敌方区域两侧。
2. 编队引导先围绕“敌方中心估计”和“目标区域 R_target”生成基础引导几何。
3. 远距离阶段先压缩接敌，更接近朝敌方中心方向推进。
4. 距离缩短后，再逐步展开为左右分侧包夹。
5. 责任方向还会对基础引导点产生塑形修正，所以最终引导点不是单纯的敌中心左右对称点。

推荐构图：
1. 整体采用“主图 + 右侧两个小插图”的布局。
2. 主图左下区域画4架红色我方飞机，体现两组双机对编队。
3. 在我方4机之间画一个“编队中心”标记点。
4. 主图右上区域画“敌方中心估计”点。
5. 以敌方中心估计为圆心画浅蓝半透明圆形“目标区域 R_target”。
6. 从编队中心指向敌方中心估计画一条明显的主引导方向箭头。
7. 在目标区域周围布置若干引导点，但这些引导点必须体现“渐进展开”的逻辑，不能画成从一开始就完全理想对称展开的静态结构。
8. 从各架我方飞机向各自引导点画虚线或细线引导关系，保持清晰但不要太乱。

主图必须体现以下几层关系：
1. 编队中心
2. 敌方中心估计
3. 目标区域 R_target
4. 主引导方向
5. 基础引导点
6. 责任方向修正后的最终引导点

建议的视觉表达方式：
1. 基础引导点可以用一种较浅的蓝色小圆点表示。
2. 修正后的最终引导点可以用另一种更实的蓝色点表示。
3. 可以用短虚线或淡色箭头表示“由基础引导点向最终引导点的修正”。
4. 但一定要克制，不能让图面过于复杂。

右上角小插图：
主题是“远距离压缩接敌 -> 近距离逐步展开”。
1. 左小图表现远距离阶段：
   - 多架飞机更朝向敌方中心
   - 展开量较小
2. 右小图表现近距离阶段：
   - 多架飞机向左右分开
   - 引导点明显分侧
3. 中间用箭头连接
4. 只保留极少文字，例如“远距离压缩”“近距离展开”

右下角小插图：
主题是“全部飞向中心”和“分侧引导”的对比。
1. 左侧画不优情况：
   - 多架飞机航迹拥挤到中心
   - 扫描重叠明显
   - 用叉号表示
2. 右侧画更优情况：
   - 多架飞机分侧接敌
   - 几何更舒展
   - 用对勾表示
3. 不要写长文字，只做极简视觉对比。

允许保留的少量标签：
- 编队中心
- 敌方中心估计
- 目标区域 R_target
- 主引导方向
- 基础引导点
- 最终引导点
- 远距离压缩
- 近距离展开

禁止事项：
1. 不要画成旧版那种“一开始就理想对称分布到圆边两侧”的图。
2. 不要画成纯流程图。
3. 不要让文字盖过图形。
4. 不要添加文档里没有的新模块。

最终效果要求：
1. 一眼看出“先向敌中心压缩接敌，再逐步展开到分侧引导”。
2. 一眼看出责任方向会修正引导点。
3. 风格必须和我上传的参考图片一致。
4. 输出高清 PNG，适合直接插入论文正文。
```

## 图3.4 独立 Prompt

```text
请严格按照我这次上传的参考图片风格，重绘一张“探测模式切换关系示意图”。

重要要求：
1. 风格必须严格模仿我上传的参考图片，只模仿视觉风格，不复制原图内容。
2. 必须是白色背景、清爽规整、论文技术示意图风格。
3. 这张图虽然是模式切换关系图，但也不能画成软件工程式的密集流程框图，要保持图形简洁、文字很少、适合论文展示。
4. 不能使用黑底、霓虹、UI大屏、科幻面板风格。

这张图必须表达当前正确逻辑：
1. 预警可用时，优先进入 DIRECTED。
2. 目标丢失时，进入 SEARCH。
3. 预警失效但仍保留历史信息、融合信息或预测上下文时，也进入 SEARCH。
4. SEARCH 在信息恢复后优先回到 DIRECTED。
5. 只有当预警不可用且预测上下文也不足时，才退化到 SWEEP。
6. SWEEP 是最低信息条件下的退化模式。

推荐整体布局：
1. 三个主模块并列排布：
   - 左：SWEEP
   - 中：DIRECTED
   - 右：SEARCH
2. DIRECTED 放中间，作为主工作模式。
3. 每个主模块用一个浅色边框框起来，内部配一个小型雷达扇区示意图。
4. 箭头关系要清楚，但不要太多交叉。

每个模块内部要求：
1. SWEEP
   - 显示较宽、均匀、前向铺开的扇区
   - 文字极简：SWEEP / 均匀覆盖
2. DIRECTED
   - 显示较集中、沿已知方向收敛的扇区
   - 文字极简：DIRECTED / 定向截获
3. SEARCH
   - 显示围绕不确定责任区间展开的恢复搜索扇区
   - 文字极简：SEARCH / 预测搜索

箭头与触发词必须这样设计：
1. SWEEP -> DIRECTED
   - 触发词：预警可用
2. DIRECTED -> SEARCH
   - 触发词：目标丢失
3. DIRECTED -> SEARCH
   - 同时还要表现另一类触发：
   - 预警失效但仍有预测
   - 可以合并为一个辅助标签，放在去往 SEARCH 的箭头附近
4. SEARCH -> DIRECTED
   - 触发词：信息恢复
5. SEARCH -> SWEEP
   - 触发词：预测不足

图中必须明确表达的语义：
1. SEARCH 不是普通宽扫，而是建立在历史/融合/预测上下文上的恢复搜索。
2. SWEEP 不是主模式，而是信息条件最差时的退化模式。
3. 不能把“信息恢复”错误画成 SEARCH 回 SWEEP。
4. 不能缺少“预警失效但仍有预测 -> SEARCH”这条逻辑。

建议的图形细节：
1. 每个模块中的雷达扇区都用浅蓝半透明表示。
2. 模块标题清晰，中文说明极短。
3. 箭头可以用深色或红色强调，但整体仍要保持参考图那种克制的学术风格。
4. 如果画面允许，可在 SWEEP 模块旁边补一个很小的附注：
   - 无预警且无有效预测
   但文字要小而简洁。

允许保留的少量文字：
- SWEEP / 均匀覆盖
- DIRECTED / 定向截获
- SEARCH / 预测搜索
- 预警可用
- 目标丢失
- 预警失效但仍有预测
- 信息恢复
- 预测不足

禁止事项：
1. 不要画成长篇状态机。
2. 不要把 SEARCH 画成普通扇区扫描而没有“预测责任区间”含义。
3. 不要沿用旧版错误切换关系。
4. 不要让文字过多。

最终效果要求：
1. 一眼看清三种模式的功能差异。
2. 一眼看清各模式之间在什么条件下切换。
3. 风格必须和我上传的参考图片一致。
4. 输出高清 PNG，适合直接放入论文正文。
```

## 图3.5 独立 Prompt

```text
请严格按照我这次上传的参考图片风格，重绘一张“多机雷达扫描扇区与责任区划分示意图”。

重要要求：
1. 风格必须严格模仿我上传的参考图片，只模仿视觉风格，不复制原图内容。
2. 必须是白色背景、二维俯视、学术论文技术示意图。
3. 文字必须非常少，图形表达必须占主导。
4. 这张图必须完全围绕“多机协同扫描 + 责任划分 + 谁扫哪里”来画，不能再画成旧版那种只是扇区宽度对比的图。

这张图必须表达的核心内容：
1. 多机扫描不是平均按编号摊开，而是按责任方向或责任区间组织。
2. DIRECTED 模式下，预警方位有效，4机围绕责任槽位进行定向分工。
3. SEARCH 模式下，预警短时失效但仍有预测上下文，4机围绕预测责任区间进行“主搜索 + 补盲”分工。
4. SWEEP 只是在最差信息条件下的退化均匀覆盖，不应占主画面主体。
5. 图中必须让人一眼看出“谁负责哪一片方向或哪一段责任区间”。

推荐布局：
整张图采用“左侧 DIRECTED 主图 + 右侧 SEARCH 主图 + 角落一个 SWEEP 小插图”的结构。

左侧主图：DIRECTED 模式下的责任槽位分配
1. 下方画4架红色我方飞机，横向排开或略带编队层次。
2. 上方画由预警给出的若干蓝色目标方位点或蓝色目标方向标记。
3. 在这些目标方位上整理出4个责任槽位，可以用4条淡蓝责任中心线、4个浅蓝责任扇区，或4个责任方向扇面来表现。
4. 每架飞机向不同责任槽位展开扫描，不能全部扇区重叠在中部。
5. 每架飞机前方有各自的半透明扫描扇区，扇区中心略有偏转差异，体现“多机分工”。
6. 重点表达：
   - 预警方位集合 -> 责任槽位
   - 飞机 -> 对应责任槽位
   - 减少中部重叠
   - 左右方向分工明确

右侧主图：SEARCH 模式下的预测责任区间搜索
1. 下方同样画4架红色我方飞机。
2. 上方不再画清晰目标方位点，而是画一个或两个较宽的浅蓝预测责任区间，形状可以是弧形条带、较宽扇带、或不确定责任弧段。
3. 其中两架几何条件较好的飞机承担主搜索责任，其扫描扇区更明显、更靠近责任区间中心。
4. 其余飞机承担补盲或接续覆盖，扫描扇区更偏侧或更浅色。
5. 必须明显看出：
   - 不是4架飞机同时无差别宽扫
   - 而是有主搜索、有补盲、有责任区间
6. 可以用极少标签标出：
   - 主搜索
   - 补盲
   - 预测责任区间

角落小插图：SWEEP 退化模式
1. 只做很小的辅助插图，不抢主体。
2. 画一个简单的宽前向均匀扇区覆盖。
3. 只表达：无预警且预测不足时，退化为均匀覆盖。
4. 文字极简：
   - SWEEP
   - 均匀退化覆盖

图中必须准确体现的语义：
1. DIRECTED 不是固定窄扇区静态图，而是围绕责任槽位的多机定向组织。
2. SEARCH 不是平均宽扫，而是围绕预测责任区间的有组织恢复搜索。
3. SWEEP 只是最低信息条件下的退化模式。
4. 责任划分必须成为这张图的主角，而不是附属概念。

允许保留的少量标签：
- DIRECTED
- SEARCH
- SWEEP
- 责任槽位
- 预测责任区间
- 主搜索
- 补盲
- 多机分工

禁止事项：
1. 不要画成只有“SWEEP vs DIRECTED 扇区宽度对比”的旧图。
2. 不要把 DIRECTED 固定写死成某一个单独扇宽。
3. 不要完全不画 SEARCH。
4. 不要完全不画责任槽位或责任区间。
5. 不要把4机扇区全部重叠到中心，导致看不出责任划分。

视觉要求：
1. 多用浅蓝半透明扇区、细虚线责任方向线、清楚的箭头关系。
2. 我方飞机保持红色体系，责任区间和扫描扇区保持蓝色体系。
3. 整体留白充足，构图规整，和参考图视觉语言一致。
4. 让人一眼看出：
   - DIRECTED：围绕责任槽位的多机定向分工
   - SEARCH：围绕预测责任区间的主搜索与补盲
   - SWEEP：信息最差时的均匀退化覆盖

最终效果要求：
1. 这张图必须比旧图更符合文档当前含义。
2. 必须是“图居多、字很少、但责任划分一眼能懂”。
3. 风格必须和我上传的参考图片一致。
4. 输出高清 PNG，适合直接插入论文正文。
```

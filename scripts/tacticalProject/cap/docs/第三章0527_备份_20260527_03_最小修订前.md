第三章  基于“不确定性传播-协同闭环”七层联动的协同探测决策方法
3.1引言
现代空战已进入超视距作战时代，战场态势感知能力成为制胜关键。预警机凭借其远距离探测能力可提供早期预警，但探测精度较低；战斗机火控雷达探测距离有限，但可提供高精度目标定位。因此，如何有效融合这两类异构传感器信息，实现从预警机粗略探测到火控雷达精确跟踪的快速转换，是当前亟待解决的关键技术问题。本章针对该问题建立数学模型，并在此基础上给出协同探测决策与雷达扫描分配算法。
3.1.1 协同探测决策问题定义
考虑由 N 架战斗机组成的编队执行空中巡逻（Combat Air Patrol, CAP）任务（本文取 N=4 的双机对编队形），编队依托预警机与战斗机火控雷达两类信息源（预警机提供远程目标信息，战斗机火控雷达为机载传感器）编队配置与战斗机火控雷达两类传感器。预警机具有远距离探测能力（探测距离记为 R_awacs），但位置精度较低（位置误差记为 σ_awacs），更新周期为 T_awacs；火控雷达探测距离较近（探测距离记为 R_radar，本文以进入该门限作为“到位”判据），但位置精度高（位置误差记为 σ_radar），扫描周期可变（由第3.5节体制参数确定）。两类传感器精度关系满足：
σ_awacs≫σ_radar
Ω_awacs≫Ω_radar
其中 Ω_awacs=360° 为预警机视场角（全向），Ω_radar∈{20°,60°,120°} 为火控雷达方位扫描视场角（对应NARROW/MEDIUM/WIDE三档扫描模式；在3.5节中亦采用等价的“方位半宽”表述 θ_range∈{10^∘,30^∘,60^∘}，满足 Ω_radar=2θ_range）。
在动态对抗环境下，从预警机探测到目标到火控雷达建立稳定航迹这一阶段，如何规划编队的引导路径（航向、速度、编队协调），实现最短时间引导编队到达敌方大致位置，为后续雷达精确探测创造条件。
本文研究的协同探测决策作用范围覆盖“预警发现—编队引导—雷达截获—稳定保持”全过程：从预警机首次探测到目标，到目标进入火控雷达探测范围（距离门限 R_radar），再到进入火控雷达探测范围后的稳定保持阶段。主关注为 0–R_radar 阶段的“预警引导协同探测”（航向/速度/编队协调）；进入 R_radar 门限后，本文给出与该阶段衔接的雷达扫描模式与扫描分配策略（第3.5节），用于“到位后的截获与稳定跟踪”所需的资源调度，但不讨论武器发射与战术机动规划，相关环节通过高精度航迹接口与后续模块解耦。
3.1.2任务场景约束
重要约束（初始态势）：在当前任务场景中，敌方初始航向固定为180°（由北向南的对头接近初态），但从仿真开始后敌方可根据机动策略在任意时刻改变航向与速度（如转向、上高下高等），因此敌方航向是时变且不确定的。该约束意味着：算法设计不应依赖“来袭方向恒定”的假设，而应以机动不确定性传播为核心，通过对敌方未来可达域/置信域的滚动估计实现引导。
我方初始状态：编队配置：左编队（A0100长机+A0200僚机），右编队（A0300长机+A0400僚机）；初始航向：长机0°（朝北），僚机180°（朝南）；初始位置：在算法设计中视为给定（可为任意满足任务约束的配置）；巡逻状态：热段（长机，雷达开机）与冷段（僚机，雷达关机）交替。
敌方初始状态：初始航向：180°（由北向南的对头接近初态），但航向可随时间变化（机动不确定）；初始距离：300-400km（典型值300km）；编队空间分布：可能为密集排列、标准间距、分散排列、纵队排列、宽正面排列等任意一种；高度分布：可能为高高度、中高度、低高度、混合高度、阶梯高度、突现高度中的任意一种；速度配置：可能为正常速度、低速、高速、加速、混合速度中的任意一种。

3.2系统状态空间模型
3.2.1目标运动模型
为描述目标的机动特性，本文采用交互多模型（Interacting Multiple Model, IMM）方法，包含四个子模型：匀速直线运动（Constant Velocity, CV）、协调转弯（Coordinated Turn, CT）、匀加速运动（Constant Acceleration, CA）和Singer随机机动模型。IMM方法通过多个运动模型的并行运行和概率加权融合，能够自适应地估计目标的多种机动模式，从而有效处理敌方机动不确定性。
(1) 匀速直线运动模型（CV）
CV模型假设目标在二维平面内以恒定速度做直线运动，适用于目标保持航向不变的情况。目标状态向量定义为 x_k=[x,x ̇,y,y ̇]^T，其中 (xⓜ,y) 为目标在二维平面内的位置坐标，(x ̇ⓜ,y ̇ ) 为目标的速度分量。CV模型的状态方程为：
x_(k+1)=F_CV x_k+G_CV w_k 									(3-1)
其中状态转移矩阵 F_CV 描述了位置和速度在时间步长 Δt 内的线性演化关系：位置分量等于上一时刻位置加上速度乘以时间步长，速度分量保持不变。过程噪声驱动矩阵 G_CV 将过程噪声 w_k 映射到状态空间，具体形式为：
F_CV=[■(1&Δt&0&0@0&1&0&0@0&0&1&Δt@0&0&0&1)],G_CV=[■((Δt^2)/2&0@Δt&0@0&(Δt^2)/2@0&Δt)] 					(3-2)
过程噪声 w_k∼N(0,Q_CV) 为零均值高斯白噪声，用于建模目标运动中的随机扰动。协方差矩阵 Q_CV=q_CV⋅I，其中 q_CV 为过程噪声强度，I 为单位矩阵。
(2) 协调转弯模型（CT）
CT模型考虑目标以恒定角速度 ω 进行协调转弯机动，适用于目标执行转弯、盘旋等机动动作的情况。状态向量扩展为 x_k=[x,x ̇,y,y ̇,ω]^T（5维），增加了角速度 ω 作为状态分量。状态方程为：
x_(k+1)=F_CT (ω)x_k+G_CT w_k 								(3-3)
其中 F_CT (ω) 为依赖于转弯角速度的非线性状态转移矩阵，其形式考虑了转弯过程中速度方向的连续变化。G_CT为过程噪声驱动矩阵，将过程噪声w_k映射到状态空间（与 CV 类似，具体形式取决于离散化与角速度维的噪声假设）。当角速度 ω 接近零时，CT模型退化为CV模型。
(3) 匀加速运动模型（CA）
CA模型考虑目标加速度变化的情况，适用于目标执行加速、减速等机动动作。状态向量扩展为 x_k=[x,x ̇,x ̈,y,y ̇,y ̈]^T（6维），增加了加速度分量 (x ̈ⓜ,y ̈ )。状态方程为：
x_(k+1)=F_CA x_k+G_CA w_k 									(3-4)
其中状态转移矩阵 F_CA 描述了位置、速度和加速度之间的积分关系：速度等于上一时刻速度加上加速度乘以时间步长，位置等于上一时刻位置加上速度乘以时间步长再加上加速度乘以时间步长的平方的一半。G_CA为过程噪声驱动矩阵，将过程噪声映射到状态空间中。
(4) Singer随机机动模型
Singer随机机动模型用于描述目标加速度随时间连续变化、但又带有随机扰动的机动过程。其基本假设是：目标加速度不是恒定值，而是满足一阶时间相关的随机过程，即当前时刻加速度与上一时刻加速度相关，并在随机激励作用下能够逐步变化。与CA模型直接把加速度视为确定状态不同，Singer模型更强调机动保持性与随机性并存，适用于敌方执行不规则转弯、间歇加减速或难以事先确定规律的复杂机动情形。
 在二维平面内，Singer模型可将状态向量写为 (x_k=[x,x ̇,a_x,y,y ̇,a_y ]^T)。其核心假设为加速度满足一阶时间相关过程a ̇(t)=-αa(t)+w(t)其中 α=1/τ为机动时间常数的倒数，τ反映机动保持时间，w(t)为随机激励项。离散化后可写为a_(k+1)=e^(-αΔt) a_k+η_k其中η_k为离散过程噪声。该模型表明目标加速度具有“逐步衰减 + 随机扰动驱动”的特征，因此适合描述持续但不规则的随机机动过程。
(5) 模型转移概率
IMM方法通过马尔可夫链描述不同运动模型之间的转移关系。四个模型之间的转移概率由马尔可夫转移概率矩阵 Π 描述：
Π=[■(π_11&π_12&π_13&π_14@π_21&π_22&π_23&π_24@π_31&π_32&π_33&π_34@π_41&π_42&π_43&π_44 )] 							(3-5)
其中 π_ij 表示从模型 i 转移到模型 j 的概率，满足概率归一化条件 ∑_(j=1)^4▒π_ij =1。该转移矩阵反映了目标在不同机动模式之间切换的可能性，对角线元素 π_ii 通常较大，表示目标倾向于保持当前机动模式。
3.2.2传感器观测模型
传感器观测模型描述了预警机和火控雷达对目标状态的测量过程，将目标在笛卡尔坐标系中的状态（位置、速度等）转换为传感器坐标系中的观测值（距离、方位角等），并考虑测量误差的影响。
(1) 预警机观测模型
预警机作为远程探测平台，能够提供目标相对于预警机位置的极坐标观测值，包括距离和方位角。观测方程为：
z_k^awacs=h_awacs (x_k)+v_k^awacs								 (3-6)
其中观测函数 h_awacs (x) 将目标在笛卡尔坐标系中的位置 (xⓜ,y) 转换为极坐标系中的距离和方位角：
h_awacs (x)=[█(√(x^2+y^2 )@atan2(x,y))] 								(3-7)
观测函数的第一行计算目标到预警机的欧氏距离，第二行计算目标相对于预警机的方位角（以正北方向为0°，顺时针为正）。观测噪声 v_k^awacs∼N(0,R_awacs) 为零均值高斯白噪声，其协方差矩阵为 R_awacs=diag⁡(σ_awacs^2,σ_(θ,awacs)^2)，其中 σ_awacs 为距离测量精度（标准差），σ_(θ,awacs) 为方位角测量精度（标准差）；非对角元素为0，表示距离与方位角测量误差相互独立。
(2) 火控雷达观测模型
第 i 架战机的火控雷达观测模型与预警机类似，但观测值是相对于战机自身位置的。观测方程为：
z_k^(radar,i)=h_radar (x_k,x_i)+v_k^radar 							(3-8)
其中 x_i=[x_i,y_i ]^T 为第 i 架战机在笛卡尔坐标系中的位置，观测函数为：
h_radar (x,x_i)=[█(√((x-x_i )^2+(y-y_i )^2 )@atan2(x-x_i,y-y_i))] 					(3-9)
观测函数的第一行计算目标到第 i 架战机的相对距离，第二行计算目标相对于战机的方位角。观测噪声 v_k^radar∼N(0,R_radar) 为零均值高斯白噪声，其协方差矩阵为 R_radar=diag⁡(σ_radar^2,σ_(θ,radar)^2)，其中 σ_radar、σ_(θ,radar) 分别为距离与方位角测量精度； 
精度关系：两类传感器满足 σ_awacs≫σ_radar、σ_(θ,awacs)≫σ_(θ,radar)，火控雷达测量精度高于预警机，预警机探测距离更远，两者形成互补关系。
3.2.3 IMM-EKF状态估计算法
本节状态估计的目的，而在于为后续扫描区间决策提供可用的目标状态输入。预警机给出的目标位置存在误差，且目标可能发生转弯、加减速或随机机动；若直接依据瞬时观测结果安排扫描中心与扫描范围，容易出现扫描区间偏小或扫描中心偏移。因此，本文采用 IMM-EKF 对目标当前位置、速度及其不确定性进行联合估计，并输出协方差 P，作为第3.4节机动不确定性传播、最小有效扫描区间构造和后续滤波递推的基础输入。
其中，EKF（Extended Kalman Filter，扩展卡尔曼滤波）是面向非线性系统状态估计的递推方法。其基本过程包括两步：首先依据运动模型对目标下一时刻状态进行预测；随后利用当前量测对预测结果进行修正。由于本章的观测方程h(⋅) 以及部分机动模型含有非线性项，因此需在当前估计点附近进行一阶线性化，再按卡尔曼滤波形式完成更新。
IMM-EKF 用于解决“目标可能在多种机动模型之间切换”的问题。其计算流程为：先按模型转移概率对上一时刻各模型状态进行混合；再在 CV、CT、CA、Singer 四个模型下分别执行一次 EKF 预测与修正；随后利用量测残差似然更新各模型概率；最后按模型概率加权融合，得到当前时刻的统一状态估计与协方差。该协方差将直接传递给第3.4.3节，用于构造预警失效或目标机动增强条件下的最小有效扫描区间。
设共有 M_imm=4 个机动模型（CV/CT/CA/Singer），模型转移矩阵为 Π=[π_ij]，第 m 个模型在时刻 k 的状态与协方差为 (x ̂_k^((m) )ⓜ,P_k^((m) ) )，模型概率为 μ_k^((m) )。
算法3.1 IMM-EKF状态估计（单目标）
输入：上一时刻各模型状态/协方差/概率 {(x ̂_(k-1)^((m) ),P_(k-1)^((m) ),μ_(k-1)^((m) ))}，转移矩阵 Π，当前观测 z_k（预警机或雷达），过程噪声 {Q^((m) ) }，观测噪声 R。
输出：融合状态 x ̂_k，融合协方差 P_k，各模型后验 {(x ̂_k^((m) ),P_k^((m) ),μ_k^((m) ))}。
1   for j ← 1 to M_imm do // ① 模型混合：对每个模型 j，计算其混合初值（状态与协方差）
2       c_bar (j)  ← Σ_i π_ij (i)_μ^(k-1) // 混合权重归一化常数：所有模型转移到模型j的概率加权和
3       for i ← 1 to M_imm do (i∣j)_μ^(k-1) ← π_ij (i)_μ^(k-1) / c_bar (j) // 混合概率：模型 i在给定模型j下的条件概率
4       x_(0,j) ← Σ_i (i∣j)_μ^(k-1) (i)_x ̂^(k-1) // 混合状态：按混合概率加权融合各模型上一时刻状态，作为模型 j的预测初值
5       P_(0,j) ← Σ_i (i∣j)_μ^(k-1)[ (i)_P^(k-1) + ((i)_x ̂^(k-1)−x_(0,j)) 〖(·)〗^T ] // 混合协方差：含各模型协方差与状态误差外积项，保证协方差一致性
6   for j ← 1 to M_imm do // ② 各模型 EKF 预测与量测更新：对每个模型独立执行 EKF 一步
7       x_(pred,j) ← f^((j) )(x_(0,j)); P_(pred,j) ← F^((j) ) P_(0,j) F^((j)T) + Q^((j) ) // EKF 预测：用模型的非线性/线性状态转移函数预测状态与协方差
8       K_j ← P_(pred,j) 〖H^T  (H P_(pred,j)  H^T  + R)〗^(-1)
9       (j)_x ̂^k ← x_(pred,j) + K_j (z_k − h(x_(pred,j))); (j)_P^k ← (I − K_j H) P_(pred,j) // 状态更新：用创新（量测残差）修正预测状态；协方差更新：量测后不确定性减小
10      ν_j ← z_k − h(x_(pred,j)); S_j ← H P_(pred,j) H^T + R
11      Λ_j ← N(ν_j; 0, S_j); (j)_μ^k ← Λ_j c_bar (j) / Σ_l Λ_l c_bar (l)
12  x ̂_k ← Σ_j (j)_μ^k (j)_x ̂^k // ④ 融合状态：按更新后的模型概率加权融合各模型状态，得到最终估计
13  P_k ← Σ_j (j)_μ^k[ (j)_P^k + ((j)_x ̂^k−x ̂_k) 〖(·)〗^T ]
14  return (x ̂_k, P_k, {(j)_x ̂^kⓜ,(j)_P^kⓜ,(j)_μ^k }) // 返回融合状态、融合协方差，以及各模型的后验状态、协方差与概率（供下一时刻使用）


式中 〖(·)〗^T 表示前一项误差向量与其转置的外积，即 P_(k-1)^((i) )+(x ̂_(k-1)^((i) )-x ̂_(k-1)^(0(j)))(x ̂_(k-1)^((i) )-x ̂_(k-1)^(0(j)) )^T 与融合时的类似项。
 从决策用途看，IMM-EKF 每处理一次新量测，输出的不是单一点坐标，而是“目标当前位置 + 位置不确定性范围”。当预警机信息连续可用时，该结果用于缩小定向扫描责任区；当预警机信息失效或目标连续机动时，该结果用于外推目标可能位置，并据此重新组织多机搜索责任。
在单目标、单次量测下，对多模型（CV/CT/CA/Singer）做一次完整的 IMM 步：先按转移概率混合各模型上一时刻的状态与协方差得到各模型的混合初值；再对每个模型做 EKF预测与更新，并用当前量测的创新似然更新模型概率；最后按模型概率加权融合得到当前时刻的融合状态与协方差，供第3.4.2节置信域预测与滤波递推使用。
3.3优化目标与约束条件	
3.3.1优化目标函数
协同探测阶段的核心任务，不是单纯优化编队飞行过程，而是在给定雷达体制与多机可用性约束下，以尽可能短的时间完成对全部目标的发现与持续保持，并在预警失效或目标机动增强时，动态构造覆盖目标可能位置的最小有效扫描区间。因此，本节将协同探测决策目标概括为“最快发现、最小有效扫描、有限资源分配”三项内容。
具体而言，协同探测决策需要同时回答以下三个问题：其一，在预警信息有效时，如何根据目标方位集合和我方可用飞机状态，尽快将扫描责任分配到各机并形成对全部目标的有效覆盖；其二，在预警信息失效或目标机动导致空间预测困难时，如何利用状态估计与无量测预测结果构造最小有效扫描区间，避免扫描范围不足；其三，在机载雷达资源受限条件下，如何兼顾目标发现速度与持续跟踪保持。
在当前实现中，协同探测任务分配分为两类情况：当预警信息有效时，系统依据目标方位集合、敌方中心估计结果和我方飞机当前朝向关系，优先形成“4个目标责任方向—4架飞机”的首轮责任覆盖；若几何条件允许，则各机分别对一个目标方向承担主责，若某一时刻仅有少数迎敌向飞机具备直接火控条件，则先由其承担前出搜索责任，其余飞机在转向到位后接续对应责任；当预警信息失效或目标连续机动导致空间预测困难时，系统转而依据 IMM-EKF 预测结果和置信区域，将搜索责任优先分配给当前具备有效火控雷达几何条件的飞机。考虑当前 CAP 双机对、冷热交替巡逻和迎敌几何关系，初始阶段通常仅有少数迎敌向飞机承担主搜索责任，其余飞机在转向到位后再接入协同覆盖。
协同探测决策的总体目标是在满足约束条件下，最小化加权代价函数：
(min)┬{θ_i (t),v_i (t)}  J=α_1⋅T_max+α_2⋅C_resource+α_3⋅P_miss 	(3-10)
其中：T_max=〖max⁡〗_i T_i：占位时间，完成全目标有效发现或建立期望跟踪状态所需的总体时间；     后
C_resource：资源代价，表示扫描扇区宽度、扫描周期、可用雷达数量以及多机扫描责任展开带来的资源占用强度。该项主要体现在扫描扇区宽度、扫描周期以及多机扫描中心分布三个方面：扇区越宽、扫描周期越长，或多机扫描中心展开越大，说明系统为扩大覆盖范围投入的探测资源越多；
P_miss：目标丢失概率，表示目标脱离期望扫描覆盖或稳定跟踪状态的风险；
{θ_i (t),v_i (t)}：决策变量集合，包括每架战机的航向序列和速度序列；
α_1,α_2,α_3：权重系数，反映不同目标的相对重要性；
到达时间定义：第 i 架战机到达目标区域的时间 T_i 定义为：
T_i=min{t:||p_i (t)-p ̂_enemy ||≤R_target} 							(3-11)
其中 p ̂_enemy 为估计的敌方编队中心，R_target 为目标区域半径（考虑预警机误差和敌方分布范围）。

3.3.2约束条件
协同探测决策优化问题需满足以下约束条件：
(1) 速度约束
每架战机的速度需在允许范围内：
v_min≤v_i (t)≤v_max,∀i,∀t∈[0,T_i] 									(3-12)
其中 v_min 和 v_max 为战机的最小和最大速度限制。
(2) 航向变化率约束
航向变化需满足物理限制：
|θ_i (t+Δt)-θ_i (t)|≤Δθ_max⋅Δt,∀i,∀t 					(3-13)
其中 Δθ_max 为最大航向变化率（度/秒），Δt 为时间步长。
(3) 加速度约束
速度变化需满足加速度限制：
|v_i (t+Δt)-v_i (t)|≤a_max⋅Δt,∀i,∀t 				(3-14)
其中 a_max 为最大加速度限制。
(4) 编队安全距离约束
编队内战机需保持安全距离：
||p_i (t)-p_j (t)||≥d_safe,∀i,j∈N_i,∀t 				(3-15)
其中p_i (t)、p_j (t)为第i、j架战机在时刻t的位置向量（二维平面坐标）， d_safe 为最小安全距离。
(5) 编队同步到达约束
同一编队内的战机到达时间差需在允许范围内：
|T_i-T_j |≤ΔT_sync,∀i,j∈N_i 							(3-16)
其中 ΔT_sync 为允许的最大同步时间差。
(6) 目标区域覆盖约束
所有战机的引导路径需覆盖敌方可能出现的置信区域：
⋃_(i=1)^N▒ {p_i (t):t∈[0,T_i]}⊇R_enemy 					(3-17)
其中 R_enemy 为敌方可能出现的置信区域（考虑预警机误差和敌方分布范围）。
(7) 探测资源约束
为保持体制一致性，单机稳定跟踪目标数不超过(N_trk^maxⓜ=6)；对态势级扫描形成目标数，则按不超过10个的资源评估约束控制搜索责任展开。该约束用于考核系统在“最小资源投入”条件下维持期望跟踪状态（态势级或火控级）的能力。
3.3.3分层近似求解思路
为使加权代价函数与后文算法一一对应，本文在算法设计中采用“目标函数—子问题—求解流程”的一致化映射：将加权代价函数拆解为若干可在线求解的子目标，并在滚动时域内近似最优。
时间最优项 T_max：对应第3.4节“规划层+协调层”。算法3.4给出编队级引导目标点 p_i^* 与 θ_i^* 的构造，算法3.5对同编队飞机的到位节奏做有限修正，压缩过大的时间离散，从而在滚动在线框架下逼近最小截获时间。
资源代价项 C_resource：对应第3.5节 “雷达资源调度”。其实现本质是将扫描模式、扫描半宽和多机责任展开视为离散资源决策，在满足目标发现与保持要求的前提下，降低扫描周期、覆盖角以及冗余责任展开带来的探测资源占用。 
丢失概率项 P_miss：对应第3.4.3节“预测层+区域层”与第3.5.2节“搜索模式”。式(3-22a)–(3-22d)把敌方机动与信息间歇丢失映射为置信域膨胀 σ_man (t)，从而把“丢失风险”转化为可计算的覆盖约束（式(3-17)、式(3-31)/(3-32)/(3-33)）。
本文采用分层滚动决策框架（每周期按“信息→估计→预测→区域→规划→协调→执行”顺序更新），并结合离散候选集上的枚举与代价比较进行在线求解：例如扫描模式在集合 {NARROWⓜ,MEDIUMⓜ,WIDE} 上取效用最大者（第3.5.1（2）节），分散角在离散候选集 D={0°,5°} 上选取（第3.5.2节由覆盖约束推导），航向/速度由算法3.4/3.5 给出。该方式用离散搜索与解析构造替代全局连续优化，每一步均由明确的目标与约束驱动，满足实时性要求。下面第3.4节在上述模型与约束基础上，给出协同探测决策的具体算法设计。
3.4协同探测决策算法设计
根据第3.3节建立的优化目标与约束条件，协同探测决策采用分层滚动方式：在每个决策周期内基于当前置信域与约束更新编队引导与速度协调；式(3-10)为理想化的全局优化目标，因实时性与可解性约束，本文通过滚动实施在有限时域内逼近该目标，而非保证全局最小。本章给出上述问题的分层滚动求解框架及信息可用性评估、敌方编队估计、机动不确定性传播与置信域预测、编队级路径引导、速度协调与动态路径调整等核心算法。
3.4.1总体架构与滚动决策主循环
为突出“从预警引导到 R_radar 门限”的主任务，并显式处理“敌方航向时变”的机动不确定性，本文采用分层滚动决策框架：每个决策周期 k（典型 0.2s）基于最新预警信息与己方状态，更新敌方置信域并重新计算编队级引导目标与速度协调策略；当编队中任一战机与敌方中心距离不大于 R_radar 时，切换至第3.5节雷达扫描分配流程。总体流程如下。
算法 3.2 协同探测分层滚动决策主循环（0–R_radar 主任务）
输入：预警机航迹 Z_k（目标位置与最后更新时间），我方状态 S_k^F（各机位置、航向、速度），当前时间 t_k。
输出：每机飞行引导指令 u_(i,k)^fly=(θ_i^*,v_i^*)；若已进入 R_radar 门限则含雷达扫描指令 u_(i,k)^scan。
1   Q_awacs ← 按式(3-18)计算；target_lost ← 按式(3-19)判据 // 信息层：预警质量与丢失标志
2   〖p̂〗_enemy ← 基于 Z_k 更新（第3.4.3（1）节）// 估计层：敌方编队中心
3   σ_man (t_k) ← 算法3.3 // 预测层：机动不确定性传播与置信半径
4   σ_enemy (t_k), R_target (t_k) ← 第3.4.3（2）节 // 区域层：分布范围与目标区域半径
5   {*_p^iⓜ,*_θ^i } ← 算法3.4（编队级引导目标与航向） // 规划层：每机目标点与目标航向
6   {*_v^i } ← 算法3.5（速度协调）// 协调层：满足同步到达的速度
7   for i ← 1 to N do 〖fly〗_u^i ← 将 (*_θ^i, *_v^i) 转为航向/速度控制量（第3.4.5节）// 执行层：目标航向/速度→控制量
8   if 〖min⁡〗_i ∥p_i-p ̂_enemy∥ ≤ R_radar then 进入第3.4.5节扫描分配，得到 〖scan〗_u^i // 门限判断：到位则切雷达扫描
9   return {〖fly〗_u^i }（及可选的 〖scan〗_u^i）

上述算法表明，每个决策周期（如 0.2 s）按“信息→估计→预测→区域→规划→协调→执行”顺序更新一次：先评估预警机信息质量与目标是否丢失，再估计敌方中心与置信域，接着用算法3.3/3.4/3.5 得到编队级引导目标、航向与协调速度，并转为单机控制量；当任一战机与敌方中心距离不大于 R_radar 时切换至第3.5节雷达扫描流程。该主循环将机动不确定性通过“预测层→区域层”映射为可计算的置信域，在预警丢失或敌方机动时仍能引导编队到位。
从作战阶段视角看，协同探测可视为超视距作战中的“接敌引导+目标搜索”阶段：主循环持续完成信息更新、敌情预测与编队引导机动，并在进入雷达作用距离后转入搜索确认流程。该阶段输出的编队空间态势、目标置信域与单机控制指令，可作为后续火控/交战决策阶段的统一初始条件与状态输入，从而保证后续研究与本报告在同一基础模型下连续衔接。
3.4.2信息可用性评估与不确定性量化
（1）预警机信息质量评估
在 0–R_radar 阶段，尚未形成机载雷达高精度航迹，难以对空战态势优势与威胁做完整评估。因而本文在设计层面仅引入信息可用性与可靠性评估，即对预警机信息的可用性、精度与时效性进行量化，为后续“置信域构造—路径规划—速度协同”提供输入。定义预警机信息质量指标：
Q_awacs=clip(1-σ_awacs/d_min ,0,1) 									(3-18)
其中 d_min=〖min⁡〗_j∥p_j^awacs-p_formation∥ 为编队中心到各预警目标的最小距离，clip⁡(a, 0, 1) 表示将 a 限制在 [0ⓜ,1] 内。该指标反映预警机信息精度相对于目标距离的比值，值越大表示信息质量越高。给定预警机目标位置集合 {p_j^awacs } 与我方编队中心 p_formation，先计算 d_min，再按式(3-18)得到 Q_awacs。
（2） 目标丢失检测
目标丢失检测是触发SEARCH模式的关键。定义目标丢失判据：
〖target〗_lost={█(&True,    &&if (max)┬j (t_current-t_j^last)>T_lost@&False,    &&otherwise    &&)┤			 (3-19)
其中 t_j^last 为目标 j 的最后更新时间，T_lost 为丢失判定阈值。对每个目标维护其最近一次预警更新时间戳 t_j^last。给定当前时间 t_current，若存在目标满足 (t_current-t_j^last)>T_lost，则判定该目标预警信息已丢失并置 target_lost=True；否则 target_lost=False。其输出用于滚动引导的保守化以及第3.4.5节 SEARCH 模式的触发。
3.4.3敌方编队中心与分布范围估计
（1）敌方编队中心估计
敌方编队中心估计是协同探测决策引导路径规划的基础。考虑预警机位置误差为 σ_awacs、各目标探测误差相互独立，采用等权重算术平均方法估计编队中心：
p ̂_enemy=1/M ∑_(j=1)^M▒  p_j^awacs 							(3-20)
等权重平均在探测误差相同时可最大化信息利用效率；估计误差为 σ_estimate=σ_awacs/√M（多目标平均降低误差，符合统计规律）。当预警机仅探测到部分目标时，该估计方法仍能给出合理的中心估计。
（2）敌方分布范围估计
敌方分布范围估计需综合考虑编队空间分布、预警机误差与机动不确定性。定义分布范围指标：
σ_enemy (t)=max(σ_spatial (t),σ_awacs)+σ_man (t) 			(3-21)
其中：
σ_spatial=√(1/M ∑_(j=1)^M▒〖∣∣〗 p_j^awacs-p ̂_enemy∣∣^2 )：目标位置的空间分散度（当 M=1 时取默认值 σ_default，由编队空间分布设定）；
σ_awacs：预警机位置误差（作为分布范围的下界）；
σ_man (t)：机动不确定性增量（由无量测预测与机动模型引起的时变膨胀项，见第（3）节）；
置信区域半径为 R_target=k_σ⋅σ_enemy，其中 k_σ 为覆盖系数（对应给定置信度下的覆盖）。编队空间分布自适应处理为，当预警机仅探测到部分目标时，根据探测到的目标数量推断编队空间分布：M=1 时取 σ_default（密集排列）；M=2 时取 σ_default（中等间距）；M≥4 时使用实际计算的 σ_spatial。σ_default 的具体取值在仿真中根据场景设定。
 
图3.2 敌方中心估计与目标区域估计示意
蓝色散点表示预警测量散布，黑点为中心估计，蓝色圆为目标区域半径 。该示意强调“测量越散/机动越强 → 区域越大”。）
（3）机动不确定性传播与置信域预测
由于敌方机动不确定性，会存在预警间歇丢失和连续机动的问题，预警间歇丢失指预警机更新不及时或链路中断，在一段时间内无新量测；连续机动指目标在该段时间内持续机动（如转弯、加速），其真实位置相对上次估计的偏差会随时间增大。若仅以“当前预警位置分散度 + 固定余量”构造目标区域，无法覆盖“连续机动 + 预警间歇丢失”情形下目标可能到达的范围。为此，本节将敌方机动不确定性显式建模为无量测预测下的协方差增长，并将其转化为随时间膨胀的置信域。
对目标 j 的状态估计 (x ̂_(j,k)ⓜ,P_(j,k) )，在 τ=t-t_k 的无量测预测窗口内（例如预警更新周期、间歇丢失窗口），其预测协方差按滤波预测方程传播：
├ x ̂_j (t|t_k)=f(x ̂_(j,k),τ),P_j (t|t_k )=F_j (τ)P_(j,k) F_j (τ)^T+Q_j (τ)		 (3-22a)
其中 F_j (τ) 为线性化雅可比（或模型矩阵），Q_j (τ) 为过程噪声协方差，反映机动强度上界（CV/CT/CA/Singer 等模型由IMM加权融合）。提取二维位置协方差子矩阵 P_(pos,j) (t∣t_k)∈R^(2×2)，定义 γ 置信度（自由度2）对应的卡方阈值2_χ^γ，则位置置信椭圆满足：
ε_j (t)={p:(p-p ̂_j )^T P_(pos,j) (t|t_k )^(-1) (p-p ̂_j)≤2_χ^γ} 			(3-22b)
后续路径规划中目标区域采用圆形（半径 R_target）描述；置信椭圆为任意朝向的椭圆。为与圆形目标区域一致，将椭圆用其外接圆近似，半径取椭圆最大半轴对应的置信半径：
r_j (t)=√(χ_p^2⋅λ_max (P_(pos,j) (t|t_k)))							 (3-22c)
并定义机动不确定性增量为所有目标外接圆半径的上界：
σ_man (t)=(max)┬j r_j (t) 								(3-22d)
据此，式(3-22)中的 σ_man (t) 自动体现“机动越强/丢失越久，目标区域越大”的规律；预警恢复或雷达量测进入后，P_pos 收缩，σ_man (t) 随之减小，从而使引导策略自适应收敛。
算法3.3 机动不确定性传播与置信域预测算法
输入：各目标当前状态与协方差 {(x ̂_(j,k),P_(j,k),t_k)}，当前时间 t，置信度 p（如 0.99），IMM 过程噪声 {Q_m }。
输出：机动不确定性增量 σ_man (t)，各目标预测置信半径 {r_j (t)}。
1   for j ← 1 to M do
2       τ_j← t − t_k // 按式(3-22a)：用 IMM 无量测预测得到 t 时刻的位置协方差（从全状态协方差提取 2×2 位置子块）
3       P_(pos,j) (t|t_k) ← IMM 预测位置协方差(x ̂{j,k}, p{j,k},τ_j, {Q_m} )
4       r_j (t) ←√(χ_p^2⋅λ_max (P_(pos,j) (t|t_k)))  // 式(3-22c)：置信椭圆外接圆半径 = 卡方阈值 × 位置协方差最大特征值的平方根
5   σ_man (t) ←(max)┬j r_j (t)   // 式(3-22d)：机动不确定性增量取所有目标置信半径的上界
6   return (σ_man (t), {r_j (t)})

从上述算法可以看出，在无新量测的时间段内，用 IMM 预测方程将各目标位置协方差向前传播，得到 t 时刻的位置不确定性椭圆；再按给定置信度 p 用最大特征值构造外接圆半径 r_j (t)，并取所有目标的上界作为 σ_man (t)，供第3.4.3（2）节构造 R_target。预警更新或雷达量测进入后协方差会收缩，σ_man (t) 随之减小，引导策略自适应收敛。
3.4.4编队级引导目标与航向分配算法
（1）目标区域确定
基于估计的敌方编队中心 p ̂_enemy 和分布范围 σ_enemy，确定目标区域 R_target 为以 p ̂_enemy 为中心、半径为 R_target 的圆形区域。
R_target={p:∥p-p ̂_enemy∥≤R_target} 							(3-23)
其中 R_target=k_σ⋅σ_enemy，k_σ=3 对应三倍标准差意义上的覆盖。
 
图3.3 编队引导几何关系示意
上图展示了编队级引导目标与航向分配（下述算法3.4）的核心几何关系：编队中心指向敌方中心的方向作为引导基准，目标区域为半径的圆（随敌方分布与机动不确定性自适应），两编队对的长机/僚机目标点在圆边界两侧对称分配，各机目标航向由当前位置指向各自目标点。
（2）编队级引导目标
在编队级引导目标生成之前，系统首先完成协同探测任务分配。该分配过程采用“责任方向—飞机”的责任映射：预警有效阶段，AWACS 提供带误差的目标方位集合，系统优先组织4架飞机对4个目标方向形成首轮责任覆盖；预警失效或目标连续机动阶段，分配结果转为“预测责任区间—飞机”的覆盖映射，用于确定当前哪些飞机承担主搜索、哪些飞机承担补盲或接续覆盖。
任务分配遵循三项原则。第一，优先可用原则：优先选取当前朝向责任区、处于热段且火控雷达前向可视区能够直接覆盖目标方位的飞机承担主责任；第二，最短发现时间原则：若多架飞机都可覆盖，则优先选择转向代价更小、到达目标区域时间更短的飞机先行接管；第三，最小资源原则：在责任方向已被覆盖的前提下，其余飞机不再无差别重复扫描，而是转为补盲、分散覆盖或转向接入，从而避免无效的资源重叠。
在预警信息有效时，系统依据目标方位集合构造责任方向集合，并结合敌方中心估计结果和我方飞机当前朝向，优先将4个目标责任方向分配给当前迎敌向且几何条件较优的飞机。目标方位跨度较小时，4个责任方向相互接近，系统将扫描责任压缩在较小方位范围内，以较窄扇区实现快速截获；目标方位跨度增大或目标呈宽正面分布时，责任方向随之展开，多机在责任方向附近做有限分散，形成对更宽责任区间的协同覆盖。该责任映射随目标方位分布和我方飞机可用性滚动更新。
在预警信息失效或目标连续机动导致空间预测困难时，分配对象由瞬时目标点切换为预测方位中心及其置信区间。此时系统首先依据 IMM-EKF 的无量测预测结果得到目标可能出现的方位范围，再判断当前哪些飞机仍处于迎敌向、哪些飞机的前向火控视场可以优先覆盖预测区间。考虑当前双机对和冷热交替巡逻构型，初始阶段通常只有少数迎敌向飞机具备直接搜索条件，因此这部分飞机先承担主搜索责任，其余飞机在转向到位后承担补盲或接续覆盖任务。该机制使“预警失效”不再等同于“全队同时宽扫”，而是转化为“有限可用飞机先行搜索、其余飞机延后接入”的有序责任展开。
编队级引导目标与航向分配需考虑编队关系、责任覆盖和到位节奏约束。本文在二维平面内处理航向与相对几何；编队中心到敌方中心的直接航向、各机目标点与目标航向均在水平面内计算。该算法首先计算编队中心到敌方中心的直接航向，然后结合编队关系和责任区间分配各机目标位置，最后在必要时通过速度协调对同编队飞机的到位节奏做有限修正。
算法3.4 编队级引导目标与航向分配算法
输入：我方4机位置 {p_i }，估计敌方中心 p ̂_enemy，置信区域半径 R_target，编队关系 F（两对长机-僚机）。
输出：每架战机的目标航向 {θ_i^* }、目标速度 {v_i^* }、目标位置 {p_i^* }。
1   p_formation ← (1/4) Σ_i p_i // 编队几何中心
2   Δp ← p ̂_enemy − p_formation；θ_direct ← atan2(Δp_x, Δp_y) // 编队中心→敌方中心的向量与直接航向
3   for each (lead, wing) ∈ F do  // 对每个编队对分配长机/僚机目标点
4       p_pair ← (p_lead + p_wing) / 2 // 该编队的中心
5       Δp_pair ← p ̂_enemy − p_pair；e_pair ← Δp_pair / ∥Δp_pair∥// 指向敌方的单位向量
6       *_p^lead ← p ̂_enemy − (R_target/2) e_pair；*_p^wing ← p ̂_enemy + (R_target/2) e_pair // 在目标区域边界两侧对称分配
7   for i ← 1 to N do  // 由目标点反算每机目标航向
8       Δp_i ← *_p^i − p_i；*_θ^i ← atan2(Δp_(i,x), Δp_(i,y))
9   {*_v^i } ← 算法3.5 // 速度协调，满足同步到达约束
10  return ({*_θ^i }, {*_v^i }, {*_p^i })

上述算法根据当前敌方中心估计与目标区域半径，为 4 机编队生成“引导目标点 + 目标航向 + 协调速度”：先在二维平面内计算编队中心到敌方中心的直接航向，再对每个编队对沿该方向在目标区域边界两侧对称分配长机/僚机目标点，使同一编队内两机覆盖目标区域两侧并保持编队关系；然后由各机目标点反算目标航向，并调用算法3.5得到满足同步到达约束的速度分配。R_target 大时分配自然分散，R_target 小时分配集中，从而随敌方分布与置信域自适应。
3.4.5速度协调辅助算法
速度协调在本章中属于辅助协调环节，其作用是避免同一编队内战机进入雷达工作阶段的时间过度离散，并在机动转弯后尽量保持其他飞机对目标的持续跟踪。该环节服务于“最快发现全部目标”和“保持持续跟踪”两个核心目标，不单独作为协同探测效果的主要来源。从任务链位置看，速度协调位于责任分配之后。责任方向的形成、搜索责任的展开以及扫描宽度的确定，均由信息层、预测层、区域层和扫描分配层完成；速度协调只对已经确定的责任飞机做节奏修正，用于压缩同编队飞机进入雷达工作阶段的时间差，保持责任区接入顺序稳定。因此，本章对速度协调的处理定位为支撑性手段，第三章有效性的主要来源仍然是责任分配与最小有效扫描区间构造。
（1） 速度协调问题
速度协调优化的目标是使同一编队内的战机同步到达目标区域，同时最小化速度变化代价。
(min)┬{v_i }  [(max)┬(i,j∈N_i ) |T_i (v_i)-T_j (v_j)|+λ∑_i▒ |v_i-v_nominal |^2 ]					 (3-24)
约束条件：
v_min≤v_i≤v_max,∀i
|T_i-T_j |≤ΔT_sync,∀i,j∈N_i
其中 T_i (v_i)=(∣∣p_i^*-p_i∣∣)/v_i  为到达时间。
算法3.5 速度协调优化算法
输入：{p_i }（各机当前位置），{p_i^* }（目标位置），{v_i^current }（当前速度），v_nominal（标称速度），[v_minⓜ,v_max ]（速度范围），ΔT_sync（同步时间差阈值），F（编队对集合）
输出：{v_i^* }（优化后速度）
1   for i ← 1 to N do // 计算每机当前速度下的预计到达时间
2       d_i ← ∥*_p^i-p_i∥
3       〖cur〗_T^i ← d_i / 〖current〗_v^i
4   for each (lead, wing) ∈ F do// 对每个编队对做同步决策
5       if ∣〖cur〗_T^lead-〖cur〗_T^wing∣ ≤ ΔT_sync then // 已同步则保持当前速度
6            *_v^lead ← 〖cur〗_v^lead; *_v^wing ← 〖cur〗_v^wing
7       else // 未同步：构造两候选并取代价小者
8           // 候选A：先到者减速
9           if 〖cur〗_T^lead < 〖cur〗_T^wing then // 情况A1：长机先到（长机到达时间更小）
10              〖tar〗_T^lead ← max(〖cur〗_T^lead, 〖cur〗_T^wing − ΔT_sync) // 长机目标到达时间：取当前时间与（僚机时间减阈值）的较大者，确保不早于僚机到达时间减阈值
11              A_v^lead ← clip(d_lead/〖tar〗_T^lead, v_min, v_max); A_v^wing ← 〖cur〗_v^wing // 长机候选A速度：用目标时间反算速度并限制在[v_min, v_max]内；僚机保持当前速度
12          else // 情况A2：僚机先到（僚机到达时间更小）
13              〖tar〗_T^wing ← max(〖cur〗_T^wing, 〖cur〗_T^lead − ΔT_sync)
14              A_v^wing ← clip(d_wing/〖tar〗_T^wing, v_min, v_max); A_v^lead ← 〖cur〗_v^lead
15          // 候选B：后到者加速
16          if 〖cur〗_T^lead < 〖cur〗_T^wing then
17              〖tar〗_T^wing ← min(〖cur〗_T^wing, 〖cur〗_T^lead + ΔT_sync)
18              B_v^wing ← clip(d_wing/〖tar〗_T^wing, v_min, v_max); B_v^lead ← 〖cur〗_v^lead //长机先到时：僚机加速追赶，长机保持
19          else
20              〖tar〗_T^lead ← min(〖cur〗_T^lead, 〖cur〗_T^wing + ΔT_sync) 
21              B_v^lead ← clip(d_lead/〖tar〗_T^lead, v_min, v_max); B_v^wing ← 〖cur〗_v^wing //僚机先到时：长机加速追赶，僚机保持
22          A_T^lead ← d_lead/A_v^lead; A_T^wing ← d_wing/A_v^wing // 候选A下长机的实际到达时间：用候选A速度重新计算
23          B_T^lead ← d_lead/B_v^lead; B_T^wing ← d_wing/B_v^wing
24          J_A ← ∣A_T^lead-A_T^wing∣ + λ[(A_v^leadⓜ-v_nominal )^2 ┤ + (A_v^wingⓜ-v_nominal )^2 ┤]  // 候选A代价（式3.24）：第一项为到达时间差绝对值，第二项为速度与标称速度偏差的加权平方和
25          J_B ← ∣B_T^lead-B_T^wing∣ + λ[(B_v^leadⓜ-v_nominal )^2 ┤ + (B_v^wingⓜ-v_nominal )^2 ┤] 
26          (*_v^lead, *_v^wing) ← argmin{J_A, J_B} 
27  return {*_v^i }   // 汇总各编队对得到的 v* 为全队速度指令

（符号对应：d_l,T_l^cur,v_l^cur 为长机，d_w,T_w^cur,v_w^cur 为僚机；T_l^A=d_l/v_l^A、T_w^A=d_w/v_w^A 为候选A到达时间，T_l^B、T_w^B 同理。代价与式(2.6)一致；clip⁡(x,a,b) 表示将 x 限制在 [aⓜ,b] 内。）
在给定各机当前位置、目标位置与速度范围下，对每个编队对枚举“先到者减速”与“后到者加速”两类候选策略，分别得到满足同步时间差 ≤ΔT_sync 的速度组合，再按式(2.6)的代价（到达时间差 + 与标称速度的偏差）取代价较小者作为该编队对的协调速度；汇总各编队对得到全队 {v_i^* }。在在线可解的前提下逼近编队同步到达并抑制速度偏离标称值。
3.4.6单机控制量生成
本节对应基础需求文档中“战术机动动作数学模型及控制指令求解”的执行侧实现，属于该章分层控制架构在“协同探测阶段”的任务化裁剪，而非独立控制模型。基础模型的分层链路为“战术决策层→轨迹/引导层→指令离散化层→控制转换层→物理仿真层”；其中，算法3.4/3.5给出编队级目标航向与速度，本节完成其向单机可执行控制量的离散化映射，即在每个决策周期输出航向变化率与加速度指令。
与基础模型第4章相比，本节不展开复杂复合机动原语与全轨迹规划，仅处理协同探测所需的航向/速度引导执行；但所采用的状态描述、控制量定义、约束边界与离散执行机制保持一致，因而全文基础模型同源同构。
本节将算法3.4/3.5输出的目标航向与目标速度转换为每周期可执行的航向/速度控制量，并满足航向变化率与加速度约束，起到“决策输出—执行层”的衔接作用。单机控制量生成模块将算法3.4和3.5输出的目标航向 θ_i^* 和目标速度 v_i^* 转换为航向/速度调整命令，该转换过程需满足航向变化率限制和加速度限制，以保证飞行控制的平滑性与稳定性。
航向跟踪控制律：计算航向误差 Δθ=θ_i^*-θ_i^current，并将其归一化到 [-180°,180°] 区间（若 Δθ>180° 则减去360°，若 Δθ<-180° 则加上360°）。采用带限幅的比例控制，限制航向变化率：
Δθ_cmd=clip(Δθ,-Δθ_max⋅Δt,Δθ_max⋅Δt) 							(3-25)
其中 Δθ_max 为最大航向变化率（度/秒），Δt 为控制周期。
速度跟踪控制律：计算速度误差 Δv=v_i^*-v_i^current，采用带限幅的比例控制，限制加速度：
Δv_cmd=clip(Δv,-a_max⋅Δt,a_max⋅Δt) 							(3-26)
其中 a_max 为最大加速度限制。该跟踪策略保证航向/速度平滑过渡，避免控制量突变导致的飞行不稳定。
3.4.7 动态路径调整算法
当发生预警更新、敌方机动、预警丢失或目标丢失等事件时，需对当前路径与置信域进行更新或切换扫描模式；本节给出在上述事件触发下的动态路径调整与模式切换逻辑。
（1） 路径调整触发条件
动态路径调整的触发条件定义如下事件：
预警机信息更新事件：在时刻 t 接收到新的预警观测包，且其观测时间戳（或序号）发生变化。记当前最新预警观测时间戳为 t_awacs^msg，上一轮已处理时间戳为 t_awacs^proc，则：
event_update⇔(t_awacs^msg≠t_awacs^proc) 										(3-27)
同时定义预警信息时效性量：
Δt_awacs=t-t_awacs^msg 										(3-28)
其中 Δt_awacs 为预警信息时效量，在延迟/丢失判据中使用。
敌方机动检测事件：在窗口 [t-ΔT_m, t] 内，若估计航向/速度变化满足
(max)┬j |Δψ_j |≥ψ_th 或 (max)┬j |Δv_j |≥v_th										 (3-29)
其中 Δψ_j、Δv_j 由 IMM-EKF 输出的速度矢量变化计算得到，ψ_th、v_th 为机动阈值参数。
预警机信息延迟/丢失事件：当 Δt_awacs 超过系统允许的信息时效阈值时认为预警信息已过期或丢失：
event_stalc⇔Δt_awacs>T_awacs,event_lost⇔Δt_awacs>T_(lost,awacs) 		(3-30)
其中 T_awacs 为预警更新周期（或其等效上界），T_(lost,awacs) 为丢失阈值（通常取其若干倍）。若系统显式给出 I_awacs∈{0,1}，则也可用 I_awacs=0 直接触发 event_lost。
目标丢失事件：target_lost=True（第3.4.2（2）节）
（2）动态路径调整算法
算法3.6 动态路径调整算法
输入：当前路径 {θ_i^currentⓜ,v_i^current }，预警机信息与事件标志，当前时间 t。
输出：调整后的路径 {θ_i^newⓜ,v_i^new }。
1   if 预警机信息更新 then
2       更新  p ̂_enemy（第3.4.3（1）节）；σ_man (t), R_target ← 算法3.3、第2.2.2节
3        {*_p^iⓜ,*_θ^i }  ← 算法3.4；{*_v^i }  ← 算法3.5
4   else if 敌方机动检测 then

6       {*_p^iⓜ,*_θ^i }  ← 算法3.4；{*_v^i } ← 算法3.5
7   else if 预警机信息丢失 then
8       飞行层维持滚动引导（IMM 更新 σ_man）；雷达层切换至 SEARCH（第3.4.5节）
9   else if 目标丢失 then
10      切换至 SEARCH，以最后已知状态做无量测预测构造搜索置信域（算法3.3、3.5.3（3）节）
11  for i ← 1 to N do

根据“预警更新 / 敌方机动 / 预警丢失 / 目标丢失”四类事件，决定是否重新计算敌方中心、置信域、引导目标与速度协调；若需重算则调用算法3.3/3.4/3.5，若为预警丢失或目标丢失则在飞行层继续滚动引导的同时将雷达层切至 SEARCH。最后对航向与速度做一阶平滑（系数 α），避免路径突变，输出平滑后的 {θ_i^newⓜ,v_i^new }。动态调整后重新得到的目标航向 *_θ^i 与目标速度 *_v^i仍按当前时刻的置信域与约束由算法3.3 求解，与主循环一致，在滚动意义下继续逼近式(3-10)；平滑系数 α 用于避免指令突变，不改变式(3-10)的逐周期优化结构。

3.5.3扫描任务分配
扫描任务分配的本质是“目标/区域—飞机”的责任映射。当预警信息有效时，系统优先依据目标方位集合完成快速目标分配，使各飞机尽快形成对4个目标的责任覆盖；当预警信息失效时，分配对象由瞬时目标点切换为预测方位中心与置信区间，责任形式由目标分配转为扇区分配。考虑当前双机对与冷热巡逻构型，初始阶段通常由迎敌向、具备较好火控雷达几何条件的飞机优先承担主搜索责任，其余飞机在转向到位后承担补盲或接续覆盖任务。因此，本节给出的扫描中心、扫描半宽和俯仰行数，对应的是上一层“任务分配结果”的执行化表达。前一层先确定责任方向和责任飞机，本节再把这种责任映射落实为“哪架飞机扫哪里、扫多宽、扫多快”。由此，扫描分配直接承担了把责任方向转写为机载雷达可执行指令的作用。
在选定探测模式（SWEEP、DIRECTED 或 SEARCH）后，需为每架战机分配扫描中心与扫描半宽，且须满足表3-1的约束。本节按三种模式分别给出分配策略与所用公式。
（1）推磨扫描（SWEEP）
当无预警机信息时，采用推磨扫描策略，使多机在指定扇区内均匀覆盖，避免漏检任意方向上的目标。模式与体制绑定为 MEDIUM，即扫描半宽 θ_range=30^∘（表3-1）。各机扫描中心限制在可行扇区 [-Θ_total/2+θ_range, Θ_total/2-θ_range ] 内均匀布置：中心间距取 Δθ_sweep=max⁡(0, (Θ_total-2θ_range)/(N-1))，第 i 机扫描中心为 θ_(center,i)=-Θ_total/2+θ_range+(i-1)Δθ_sweep，其中 Θ_total 为总覆盖扇区宽度（如 120^∘）。例如 N=4、Θ_total=120^∘ 时，θ_(center,i)∈{-30^∘,-10^∘,10^∘,30^∘}，四机覆盖并集为 [-60^∘,60^∘ ]。
（2）定向扫描（DIRECTED）
当有预警机目标方位信息时，采用定向扫描策略，使多机扫描中心集中在目标方向附近，以缩短截获时间。先由预警目标方位集合得到方位中心与跨度：θ_center=(θ_min+θ_max)/2 ；θ_span=θ_max-θ_min。在该模式下，系统先依据责任方向判断哪些飞机承担主扫描、哪些飞机承担补充覆盖，再在满足整体责任覆盖的前提下做有限分散。目标方位跨度较小时，预警信息能够把责任方向压缩到较窄区域，此时采用较小分散角和较窄扇区即可实现快速截获；目标方位跨度较大时，责任方向随之展开，系统相应增大机间分散角，使多机共同覆盖责任区间。这里的分散服务于责任方向完整覆盖，而非均匀摊开雷达资源。所需覆盖宽度为 Θ_req=θ_span。单机扫描半宽取 NARROW 对应值 θ_range（表3-1）。为满足覆盖，机间分散角至少为 Δθ_min=max⁡(0, (Θ_req-2θ_range)/(N-1))；工程上在离散候选集 D={0°,5°} 上选取与 Δθ_min 最接近的值作为实际分散角 Δθ_spread（即 Δθ_spread=arg⁡〖min⁡〗_(Δθ∈D)∣Δθ-Δθ_min∣）。当 Θ_req≤2θ_range 时取 0^∘ 即可；当需求超过单机可覆盖宽度时，自动取 5° 等离散值以扩大协同覆盖。各机扫描中心为 θ_center+(i-(N-1)/2)Δθ_spread，扫描半宽与模式均为 NARROW（表3-1）。
 
图3.5 多机雷达扫描扇区与责任区划分示意
（3）智能搜索（SEARCH）
当目标丢失时，采用智能搜索策略，基于第3.4节机动不确定性传播与置信域预测，在方位上覆盖目标可能出现的区域。对每个目标利用 IMM 无量测预测得到预测位置与位置协方差（算法3.1与3.3），进而得到相对编队中心的预测方位 θ_j^pred 以及方位不确定性半宽：  θ_(unc,j)=arctan⁡(r_j (t)/d_j)，其中 d_j 为编队中心到该目标预测位置的距离，r_j (t) 为置信半径（式(3-22c)）。该模式的关键在于将目标丢失后的空间不确定性转写为责任搜索区间，再由当前具备搜索条件的飞机优先承担该区间。若预测结果表明目标仍集中在有限方位范围内，则主搜索飞机围绕预测中心建立搜索覆盖；若不确定性持续膨胀，预测方位跨度接近或超过单机可有效覆盖能力，则责任区间继续扩展，并由其余转向到位的飞机接续补盲。由此，搜索模式中的“宽扇区”表示系统把预测误差转换为一个可分配、可接续、可扩展的责任搜索区间。
由各目标预测方位得到预测中心与跨度，再结合 θ_unc=〖max⁡〗_j θ_(unc,j)（必要时可适当放大，仿真中给定）构造搜索覆盖宽度 θ_(search_span)，并限制在体制允许的 60°–120° 范围内。各机扫描中心对准预测方位中心（全机同向），扫描半宽与模式取 WIDE（表3-1），以在方位上覆盖不确定性区域。
3.5.4扫描范围的计算
将目标位置不确定性（长度量纲）映射为角度域的扫描宽度时，可采用以下两种方式，二者均在体制允许的 NARROW–WIDE 角度范围内截断。
基于误差圆的简化方法：若将目标位置误差视为半径 r_error 的圆（r_error 取预警机误差 σ_awacs 或雷达误差 σ_radar），战机到目标距离为 d，则扫描角度半宽可取为 arctan⁡(r_error/d) ，即
θ_scan=2×arctan⁡(r_error/d)			 (3-31)
基于协方差椭圆的方法：当采用 IMM-EKF 等估计器时，目标位置不确定性由协方差矩阵 P 描述。提取二维位置协方差子矩阵 P_pos，做特征值分解
P_pos=VΛV^T 			(3-32)
在给定置信度 p（如 0.99）下，椭圆半轴为 a=√(χ_p^2⋅λ_max )、b=√(χ_p^2⋅λ_min )（χ_p^2 为自由度 2 的卡方阈值）。以长半轴对应角度加余量作为扫描半宽：
θ_scan=2×arctan⁡(a/d) 			(3-33)
若需再留余量可加数度（仿真中给定）。最终扫描范围需限制在表3-1中NARROW 到 WIDE 对应的角度范围内。第3.6节在上述模型与分配策略基础上，针对具体仿真对象与初始态势给出参数取值与验证指标体系。

本质区别在于：本文方法将“不确定性”显式建模并主动应对，而对照方法假设信息总是可用且准确。这一区别在信息质量下降或目标机动时尤为明显。

3.6.3评价指标定义

时效性指标：

2.雷达进入工作阶段的平均时刻（s）：所有战机雷达激活时刻的平均值，反映编队整体进入雷达主导阶段的时机。
3.雷达进入工作阶段的同步性（标准差，s）：雷达激活时刻的标准差，反映编队速度协调的效果。标准差越小，表示战机越同步地进入雷达范围。
4.平均首探延迟（s）：进入雷达主导阶段后，各目标从"雷达开始进入工作阶段"到"首次被建立有效航迹"的延迟均值。该指标反映雷达扫描模式的截获效率。
5.全目标探测补齐用时（s）：进入雷达主导阶段后，四个目标均被建立有效航迹所需的额外时间。该指标反映多目标覆盖的完整性。
6.联队完成全目标探测的时刻（s）：从仿真开始到所有目标均被探测的总时间。
连续性/覆盖指标：
1.激活后全覆盖连续性（0–1）：雷达主导阶段开始后，满足"四个目标同时被持续覆盖/跟踪"的时间占比。该指标反映系统维持全目标覆盖的能力。
2.激活后任意目标连续性（0–1）：雷达主导阶段开始后，至少有一个目标被持续覆盖的时间占比。
3.激活后平均覆盖率（0–1）：雷达主导阶段开始后，"被有效覆盖的目标数量占比"的时间平均值。该指标反映平均覆盖水平。
策略行为指标：
1.模式切换次数（次）：探测模式（DIRECTED/SEARCH/SWEEP）切换的总次数，反映系统对态势变化的响应强度。
2.各模式驻留时间（s）：各探测模式的累计驻留时间，反映系统的主要工作模式。
3.搜索覆盖累计时间（s）：SEARCH模式的累计时间，反映系统应对不确定性的时间成本。
协同效率指标：
1.目标分配基尼系数（0–1）：各战机探测目标数量的基尼系数，越大表示分工越明确。
2.战机负载基尼系数（0–1）：各战机工作负载的基尼系数，越小表示负载越均衡。
3.冗余探测比率（0–1）：多机同时探测同一目标的时间占比，反映协同冗余度。

（1）场景配置与验证目标
V01场景设置为标准对头来袭态势，敌我初始距离320 km，敌方采用标准编队（横向间隔约20 km），中高度（8.0–8.5 km），预警机全程在线。早期机动脚本包括括号机动（6 s触发）、立体分层（36 s）、单侧钩形（60 s）和回正（90 s），设计目的是在信息条件良好的前提下，检验协同探测算法的基础性能。
该场景重点验证三个核心机制：（1）基于置信目标区域的编队引导是否能够优化接近路径；（2）速度协调机制是否能够实现同步激活；（3）短时信息丢失时的模式切换决策是否能够保持覆盖连续性。
（2）协同探测算法执行过程与机制分析
阶段1：预警引导与置信区域计算（0 s–90 s）
仿真开始时，预警机立即发现4个目标，系统从PATROL状态切换到INTERCEPT状态，协同探测算法的7层架构启动。信息层判断预警机信息可用，估计层的交互式多模型扩展卡尔曼滤波开始对各目标进行状态估计。在6 s时刻，敌机触发括号机动，算法检测到机动特征（加速度变化），自动增大过程噪声协方差矩阵，使滤波器能够快速跟踪机动目标。
预测层根据估计层输出计算机动不确定性传播。在30 s时刻，算法输出显示：4个目标均被跟踪，机动不确定性标准差约75 km，敌方中心位于(39.4, 307.6) km。区域层基于机动不确定性和目标分布计算置信目标区域半径约241 km。该置信半径远大于目标实际分布范围（横向间隔20 km），体现了算法对不确定性的保守估计策略：宁可扩大搜索范围，也要确保高概率覆盖所有目标。
规划层基于置信目标区域生成编队引导指令，协调层根据各战机到敌方中心的距离差异调整速度指令。本文方法的速度协调机制使4架战机以不同速度接近目标区域，距离较远的战机加速（速度档4），距离较近的战机保持常速（速度档3），目标是使所有战机尽可能同步地进入雷达有效探测距离（200 km）。实验数据显示，本文方法中约3.1%的控制周期使用了加速指令（66/2100步），而对照方法全程保持常速。
对照方法基于预警机提供的目标当前位置进行引导，未考虑机动不确定性和目标分布范围。当目标机动导致位置估计偏差时，对照方法的引导目标点可能偏离实际目标集合中心，导致部分战机接近路径次优。
阶段2：短时丢失与模式切换（90 s–100 s）
在90 s时刻，系统检测到目标丢失（有效目标数从4降至3），这是V01场景的关键验证点。本文方法的信息层判断预警机信息质量下降，立即触发模式切换决策。算法从DIRECTED模式（±10°窄扇区，2 s扫描周期）切换到SEARCH模式（±60°宽扇区，20 s扫描周期），扩大搜索覆盖范围以应对不确定性增大。
这一模式切换决策的核心逻辑是：当预警机信息不可靠时，算法将"估计误差"转化为"覆盖范围"。SEARCH模式的宽扇区（±60°）能够覆盖更大的方位不确定性，虽然扫描周期较长（20 s），但在信息丢失窗口内能够保持对目标的持续搜索。在100 s时刻，预警机信息恢复，算法检测到有效目标数恢复至4，立即切换回DIRECTED模式以保持截获效率。
对照方法在丢失窗口内保持DIRECTED模式，未主动扩大搜索范围。这一被动策略可能导致部分目标方位超出窄扇区覆盖范围（±10°），在信息恢复后需要更长时间重新建立航迹。实验数据显示，本文方法触发2次模式切换（DIRECTED→SEARCH→DIRECTED），搜索覆盖累计时间9.8 s；对照方法无模式切换，搜索覆盖时间0 s。
阶段3：雷达主导与快速截获（168 s–212 s）
当最近敌机距离接近200 km时，雷达按距离优先顺序激活，开始建立雷达航迹。本文方法在168.2 s时刻第一架战机雷达激活，在175.8 s时刻首次锁定目标（目标B0400，延迟2.6 s），在184 s时刻系统从INTERCEPT切换到ENGAGE状态，在190.2 s时刻全目标探测完成。对照方法在195.0 s首次锁定，210.8 s全目标探测完成。
本文方法的雷达激活序列展示了协同探测算法的时效性优势。雷达激活平均时刻为182.2 s，标准差10.9 s，表明4架战机较为同步地进入雷达主导阶段。对照方法的雷达激活平均时刻为204.2 s，标准差15.8 s，同步性较差。更小的激活时间标准差意味着战机更同步地进入雷达范围，减少了"先激活战机等待后激活战机"的时间损失，使得全目标探测补齐用时缩短3.8 s（22.0 s vs 25.8 s）。
DIRECTED模式的快速截获能力在雷达主导阶段得到充分体现。本文方法的平均首探延迟为11.8 s，对照方法为14.8 s，差距3.0 s。这一差距来源于DIRECTED模式的窄扇区（±10°）和短周期（2 s）设计，能够在目标方位已知的情况下快速建立航迹。

（1）场景配置与验证目标
V02场景设置为宽正面对头来袭态势，敌我初始距离320 km，敌方采用宽正面编队（横向间隔约80 km），中高度（8.0–8.5 km），预警机全程在线。早期机动脚本包括分裂机动（敌机向外侧机动）、交叉趋势（左右两组交叉接近）、高度层对换（7 km/10 km高度交换）、二次分裂和回正，设计目的是制造敌方中心和分布方差的显著变化，检验置信目标区域的动态调整能力。
该场景重点验证三个核心机制：（1）机动不确定性传播是否能够反映机动强度变化；（2）置信目标区域是否能够自适应调整以覆盖宽正面分布；（3）多次丢失窗口下的搜索恢复是否能够保持覆盖连续性。
（2）协同探测算法执行过程与机制分析
阶段1：宽正面引导与置信区域自适应（0 s–110 s）
V02场景的宽正面编队（横向间隔80 km）对协同探测算法提出了更高要求。仿真开始时，预警机发现4个目标，敌机初始位置分别为x=-60, -20, 20, 60 km，横向分布范围达120 km。估计层的交互式多模型扩展卡尔曼滤波对各目标进行状态估计，预测层计算机动不确定性传播，区域层根据目标分布和机动不确定性计算置信目标区域。
在敌机触发分裂机动后，横向分布进一步扩大。算法检测到机动特征，自动增大过程噪声，机动不确定性标准差随机动强度增大而增大。区域层根据更新后的机动不确定性和目标分布重新计算置信目标区域半径，使其能够覆盖更大的目标分布范围。这一自适应调整机制体现了算法对目标分布变化的动态响应能力。
规划层基于更大的置信半径调整编队引导目标点，协调层根据各战机到敌方中心的距离差异调整速度指令。实验数据显示，本文方法的雷达激活平均时刻为195.5 s，标准差8.7 s；对照方法的雷达激活平均时刻为223.5 s，标准差13.6 s。本文方法的雷达激活时机提前28.0 s，同步性提升4.9 s，表明基于置信区域的引导策略在宽正面编队条件下仍能保持覆盖优势和同步性。
对照方法基于预警机提供的目标当前位置进行引导，未考虑机动不确定性和目标分布范围。当目标分布范围扩大至80 km时，对照方法的引导目标点可能无法覆盖所有目标，导致部分战机接近路径偏离目标集合中心，雷达激活时机延后。
阶段2：多次丢失窗口与搜索恢复闭环（110 s–130 s）
在110 s左右，由于机动复杂度增加（交叉趋势和高度层对换），预警机航迹出现短时丢失，有效目标数从4降至2。这是V02场景的关键验证点，检验算法在丢失窗口维持覆盖的能力。
本文方法检测到目标丢失后，立即从DIRECTED模式切换到SEARCH模式，扩大搜索覆盖范围。在110–130 s区间内，预警机信息多次丢失和恢复，算法响应为频繁的模式切换：DIRECTED→SEARCH（110 s）→DIRECTED（信息恢复）→SEARCH（再次丢失）→DIRECTED（再次恢复）。该过程重复4次，形成"丢失触发搜索—恢复后回归定向"的闭环响应。实验数据显示，本文方法触发4次模式切换，搜索覆盖累计时间19.6 s。
这一搜索恢复闭环的核心价值在于：将"丢失窗口"转化为"可覆盖的不确定区域"。SEARCH模式的宽扇区（±60°）能够覆盖更大的方位不确定性，虽然扫描周期较长（20 s），但在丢失窗口内能够保持对目标的持续搜索。在信息恢复后，算法立即切换回DIRECTED模式，利用预警机信息快速重新建立航迹。
对照方法在丢失窗口内保持DIRECTED模式，未主动扩大搜索范围。这一被动策略导致部分目标方位超出窄扇区覆盖范围（±10°），在信息恢复后需要更长时间重新建立航迹。实验数据显示，对照方法无模式切换，搜索覆盖时间0 s，激活后全覆盖连续性为0.756，显著低于本文方法的0.888，差距0.132是三个场景中最大的。
阶段3：雷达主导与补齐效率（180 s–260 s）

（2）协同探测算法执行过程与机制分析
阶段1：早期掉线与频繁模式切换（30 s–110 s）
V03场景的低空起始（3.5 km）导致预警机探测概率显著下降（约2–5%），在30 s左右即出现首次目标丢失，远早于V01/V02场景。这是三个场景中最早出现的掉线事件，充分体现了低空起始的挑战。
本文方法的信息层检测到预警机信息质量下降（有效目标数从4降至部分丢失），立即触发模式切换决策。算法从DIRECTED模式切换到SEARCH模式，扩大搜索覆盖范围以应对不确定性增大。在30–110 s区间内，预警机航迹不稳定，信息多次丢失和恢复，算法响应为频繁的"丢失触发搜索—恢复后回归定向"往返。实验数据显示，本文方法触发9次模式切换（DIRECTED ↔ SEARCH），是三个场景中最多的，搜索覆盖累计时间39.2 s，是三个场景中最长的。
对照方法在丢失窗口内主要使用SWEEP模式（扫掠覆盖10.0 s），模式切换次数较少（2次）。SWEEP模式的扫描范围虽然较宽（±45°），但扫描周期较长（30 s），可能在信息恢复后需要更长时间重新建立航迹。实验数据显示，对照方法的搜索覆盖时间0 s，扫掠覆盖时间10.0 s。
频繁模式切换策略的核心价值在于：将"断续预警窗口"转化为"可覆盖的不确定区域"。SEARCH模式的宽扇区（±60°）和中等周期（20 s）在断续预警条件下能够保持对目标的持续搜索，虽然搜索成本较高（39.2 s），但换取了更高的覆盖连续性。实验数据显示，本文方法的激活后全覆盖连续性为0.669，对照方法为0.602，差距0.067。
阶段2：异步跃升与跟踪能力（40 s–110 s）
在早期掉线的同时，敌机执行异步跃升机动（从3.5 km跃升到9 km），导致目标高度剖面在短时间内发生显著变化。这对估计层的交互式多模型扩展卡尔曼滤波提出了挑战。
本文方法的估计层采用多模型切换机制，包含低机动模型和高机动模型。当检测到目标跃升时（高度变化率增大），算法自动切换到高机动模型，增大过程噪声以适应高度变化。在目标跃升完成后，算法切换回低机动模型以保持跟踪精度。这一多模型切换机制使得算法在目标高度变化时仍能保持对目标的持续跟踪。
对照方法的跟踪能力较弱，可能在高度变化时失去跟踪。这一被动策略导致在目标跃升后需要更长时间重新建立航迹，影响覆盖连续性。实验数据显示，本文方法的激活后平均覆盖率为0.855，对照方法为0.792，差距0.063。这一覆盖率优势直接来源于算法对异步跃升的跟踪能力。
阶段3：雷达主导与鲁棒性保持（210 s–300 s）
在更恶劣的信息条件下，V03场景的首次锁定时间相对V01/V02有所延后，但本文方法仍保持了更快的全目标补齐和更高的激活后覆盖水平。本文方法在225.4 s首次锁定目标（目标B0200，延迟1.0 s），283.6 s全目标探测完成，全目标探测补齐用时67.6 s。对照方法在232.0 s首次锁定，298.6 s全目标探测完成，全目标探测补齐用时80.4 s。
本文方法的首次锁定提前幅度相对收敛（6.6 s），但全目标补齐用时仍保持显著优势（12.8 s），体现了协同探测算法在高难度条件下的鲁棒性。雷达激活平均时刻提前18.0 s（224.6 s vs 242.6 s），表明基于搜索恢复闭环的策略在低空起始条件下仍能保持覆盖优势。
速度协调机制在低空起始条件下的同步性保持得到充分体现。本文方法的雷达激活标准差为8.5 s，对照方法为18.1 s，差距9.6 s是三个场景中最大的。这一同步性优势使得全目标探测补齐用时缩短12.8 s，在高难度条件下仍保持稳定优势。

# 第三章图形重绘 Prompt

## 使用说明

以下 Prompt 用于重绘第三章中的概念示意图。统一要求如下：

- 所有图片必须严格贴近 [第三章_0524/3.1.png](D:/Pycharm/LAG/scripts/tacticalProject/cap/docs/第三章_0524/3.1.png) 的视觉风格。
- 风格关键词：`二维俯视`、`论文插图`、`技术示意图`、`浅色背景`、`矢量感`、`边界清晰`、`少文字`、`图为主`、`适合PPT和硕士论文`。
- 不要生成海报风、UI大屏风、三维渲染风、照片风、卡通风。
- 文字要少，只保留必要标题和少量标签。
- 中文文字必须清楚，适合投影。
- 图中元素应尽量用几何关系、箭头、扇区、圆域、飞机轮廓来表达。

4. 由每架飞机向对应引导点画虚线引导连线。

2. 敌方中心估计：黑色或深色小圆点。

4. 目标区域 R_target：浅蓝圆形区域。
5. 基础引导点：位于目标区域周边或前方，标记清楚但字不要多。
6. 可以适当用两种蓝色小点来区分：

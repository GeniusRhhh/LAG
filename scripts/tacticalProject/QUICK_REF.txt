【运行仿真（一条命令）】

  cd D:\Pycharm\LAG\scripts\tacticalProject && python run_with_debug.py

会自动：
  ✓ 启用调试
  ✓ 运行仿真
  ✓ 生成日志文件
  ✓ 显示日志位置

════════════════════════════════════════════════════════════════════════════════

【仿真完成后查看日志】

  type cap_results\descent_debug.log

════════════════════════════════════════════════════════════════════════════════

【搜索异常下降】

  # 查看谁下降了
  Select-String "B0200" cap_results\descent_debug.log
  
  # 查看所有下降事件
  Select-String "is_descent=True" cap_results\descent_debug.log
  
  # 查看特定时间
  Select-String "T=476" cap_results\descent_debug.log

════════════════════════════════════════════════════════════════════════════════

【日志格式（会看到）】

  [决策追踪] T=476.0s | B0200 @14458.7m
  phase=INTERCEPT | mode=NEUTRAL
  selected_action=DIVE_ESCAPE         ← 进入的函数
  action_reason=威胁接近_执行规避    ← 为什么
  command_delta_altitude=-300.0m      ← 下降命令
  is_descent=True                      ← 确认下降
  descent_magnitude=300.0m             ← 下降量

## 二、物理模型验证

### 2.1 雷达方程实现

#### ✅ **验证通过 - 符合物理原理**

**经典雷达方程：**
```
P_r = (P_t G² λ² σ) / ((4π)³ R⁴ L)
```

**模型简化实现：**
```python
# 代码：radar_manager.py 第1218行
distance_loss = -40 * math.log10(distance / 10000)  # R^4衰减规律
```

**验证：**
- R⁴衰减规律：雷达方程中，接收功率与距离的四次方成反比
- 对数域表示：-40 dB/decade = 10 × log₁₀(R⁴) ✅ **数学正确**
- 参考距离：10 km作为归一化基准 ✅ **工程合理**

#### ⚠️ **需要注意的简化**

1. **省略了发射功率、天线增益、波长等参数**
   - 原因：这些参数已折算进`base_snr`（APG-68: 42 dB, N001VE: 40 dB）
   - 影响：无法模拟雷达功率调节，但对战术仿真影响不大
   - 评价：**合理的工程简化** ✅

2. **大气衰减系数固定**
   - 代码值：0.0008 (APG-68), 0.001 (N001VE)
   - 真实值：X波段（8-12 GHz）约0.0005-0.002 dB/km，取决于湿度<sup>[6]</sup>
   - 评价：**在合理范围内** ✅

**参考文献：**
- [6] Skolnik, M.I. "Radar Handbook, 3rd Edition", McGraw-Hill, 2008

### 5.1 跟踪质量计算

#### ⚠️ **部分合理，机动因子计算有误**

**代码实现（第355-368行）：**
```python
Q_track = f_distance × (1.0 - f_time) / f_maneuver

# 机动因子
f_maneuver = 1.0 + 0.5 × (|φ_roll| / 90°)  # APG-68
f_maneuver = 1.0 + 0.8 × (|φ_roll| / 90°)  # N001VE
```

**问题：仅用滚转角评估机动性不全面**

真实雷达跟踪质量受以下因素影响：
1. **角加速度**（而非滚转角）- 反映目标机动剧烈程度
2. **距离变化率** - 快速接近/远离影响跟踪稳定性
3. **信号强度波动** - 低SNR时跟踪易丢失

**建议改进：**
```python
# 更真实的机动因子
angular_accel = calculate_angular_acceleration(target)  # rad/s²
f_maneuver = 1.0 + min(1.0, angular_accel / 0.1)  # 0.1 rad/s²为基准
```

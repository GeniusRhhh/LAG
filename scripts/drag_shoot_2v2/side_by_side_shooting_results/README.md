# 并排射击战术仿真结果目录

本目录用于存储并排射击战术仿真的所有结果文件。

## 目录结构

```
side_by_side_shooting_results/
├── README.md                           # 本说明文件
├── *.acmi                             # ACMI轨迹文件（用于TacView可视化）
├── *_trajectory_*.csv                 # 飞机轨迹数据
├── *_missile_trajectory_*.csv         # 导弹轨迹数据
├── *_missile_analysis_*.csv           # 导弹分析数据
├── *_missile_summary_*.txt            # 导弹命中总结
├── *_radar_status_*.csv               # 雷达状态数据
├── *_tactical_maneuver_analysis_*.md  # 战术机动分析报告
└── *.log                              # 仿真日志文件
```

## 文件说明

### 轨迹文件
- **ACMI文件**: 可用TacView软件打开，提供3D可视化回放
- **trajectory CSV**: 包含飞机的位置、速度、航向、高度等详细轨迹数据
- **missile_trajectory CSV**: 包含导弹的飞行轨迹和制导信息

### 分析文件
- **missile_analysis CSV**: 导弹发射、命中、脱靶等详细分析数据
- **missile_summary TXT**: 导弹交战结果的文字总结
- **radar_status CSV**: 雷达探测、跟踪、锁定状态的时序数据

### 战术分析
- **tactical_maneuver_analysis MD**: 包含战术阶段分析、机动评估、编队保持等

## 并排射击战术特点

### 战术流程
1. **NLT-MELD阶段 (90-81km)**: 长机僚机保持1-3海里水平间距，平行航向接敌
2. **MELD-MTR阶段 (81-45km)**: 继续保持编队间距，平稳飞行
3. **MTR-TR阶段 (45-41km)**: 继续保持编队间距，平稳飞行
4. **TR-DOR阶段 (41-19.6km)**: 保持编队间距，阶段末期同时发射导弹
5. **DOR-DR阶段 (19.6-14.5km)**: 执行short_skate返航，长机左转，僚机右转

### 关键指标
- **编队间距**: 目标2海里（3704m），范围1-3海里
- **同时发射**: 长机和僚机在20.6km距离同时发射导弹
- **返航机动**: 长机左侧short_skate，僚机右侧short_skate
- **火力密度**: 双机同时攻击，提高命中概率

### 优势与劣势
**优势**:
- 双机同时发射导弹，火力密度高
- 不需要复杂的编队调整，有利于快速追击
- 攻击时机集中，增加敌方防御压力

**劣势**:
- 两机发射位置重合，攻击区域相对集中
- 正面交会容易暴露于敌机火力
- 编队间距固定，灵活性相对较低

## 数据分析建议

1. **编队保持分析**: 检查整个过程中的编队间距变化
2. **同时发射验证**: 确认长机和僚机的发射时间差
3. **返航机动评估**: 分析short_skate机动的执行效果
4. **命中率统计**: 对比并排射击与其他战术的导弹命中率
5. **生存率分析**: 评估并排射击战术的飞机生存率

## 使用说明

1. 运行仿真后，所有结果文件将自动保存到此目录
2. 使用TacView打开.acmi文件进行3D可视化分析
3. 使用Excel或Python分析CSV数据文件
4. 查看Markdown报告了解战术执行情况
5. 对比不同仿真运行的结果，优化战术参数

## 注意事项

- 文件名包含时间戳，便于区分不同的仿真运行
- CSV文件使用UTF-8编码，支持中文显示
- 大型仿真可能产生较大的数据文件，注意磁盘空间
- 建议定期清理旧的仿真结果，保持目录整洁

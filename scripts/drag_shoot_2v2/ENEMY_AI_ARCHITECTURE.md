# 增强版敌方战术AI系统架构文档

## 📋 **系统概述**

增强版敌方战术AI系统（`enemy_tactical_ai_enhanced.py`）是一个完整的、稳定的敌方对抗系统，专门设计用于提供与我方DragShootTacticalTask匹配的高质量战术对抗。

### **核心设计理念**
1. **完全镜像我方系统**：实现与我方完全一致的5阶段距离控制时间线
2. **完整机动集成**：提供完整的Short Skate三阶段机动实现
3. **智能战术切换**：基于威胁评估的三种战术模式智能切换
4. **战术随机性**：集成多样化随机参数，避免可预测行为
5. **统一复用性**：支持拖曳射击、钳形夹击等多种战术场景

## 🎯 **5阶段距离控制时间线**

### **阶段定义（完全镜像我方）**
```python
tactical_distances = {
    'NLT_MELD_min': 81000,   # 81km - 远距离接敌阶段
    'MELD_MTR_min': 50000,   # 50km - 中距离交战阶段  
    'MTR_TR_min': 40000,     # 40km - 导弹目标范围阶段
    'TR_DOR_min': 35000,     # 35km - 目标范围到动态攻击范围
    'DOR_DR_min': 14500,     # 14.5km - 动态攻击到防御范围
}
```

### **各阶段具体战术机动**

#### **1. NLT_MELD阶段 (90-81km)**
- **长机行为**：平稳接敌，朝南飞行（180°）
- **僚机行为**：编队飞行，轻微左偏（175°+随机偏移）
- **战术目标**：保持编队，稳定接敌

#### **2. MELD_MTR阶段 (81-50km)**
- **长机行为**：
  - 攻击模式：轻微右偏准备攻击（190°+随机偏移）
  - 其他模式：保持南向（180°）
- **僚机行为**：保持编队，准备分离
- **战术目标**：进入交战准备状态

#### **3. MTR_TR阶段 (50-40km)**
- **长机行为**：
  - 攻击模式：15%概率启动Short Skate机动
  - 防御模式：开始规避机动（160°左偏）
  - 中性模式：保持南向
- **僚机行为**：延迟行动，10%概率启动Short Skate
- **战术目标**：导弹发射窗口，开始战术机动

#### **4. TR_DOR阶段 (40-35km)**
- **长机行为**：
  - 攻击模式：30%概率启动Short Skate机动
  - 防御模式：执行规避机动（150°）
- **僚机行为**：跟随长机，25%概率启动Short Skate
- **战术目标**：动态攻击范围，高概率机动

#### **5. DOR_DR阶段 (35-14.5km)**
- **长机行为**：强制启动Short Skate规避机动
- **僚机行为**：强制启动Short Skate规避机动
- **战术目标**：防御范围，必须机动脱离

## ⚔️ **三种战术模式系统**

### **1. 攻击模式 (AGGRESSIVE)**
- **触发条件**：低威胁环境，导弹发射窗口
- **行为特征**：
  - 主动接敌，优先发射导弹
  - 高概率启动Short Skate机动
  - 直接攻击航向选择
- **概率权重**：低威胁60%，中威胁30%

### **2. 防御模式 (DEFENSIVE)**
- **触发条件**：高威胁环境，导弹威胁
- **行为特征**：
  - 规避机动，威胁回避
  - 防御性定位和航向选择
  - 强制Short Skate规避
- **概率权重**：严重威胁100%，高威胁70%

### **3. 中性模式 (NEUTRAL)**
- **触发条件**：中等威胁，平衡状态
- **行为特征**：
  - 平衡方法，根据态势灵活调整
  - 保持编队和基本机动
  - 稳定的战术响应
- **概率权重**：默认模式，其他情况

- **重新攻击概率**：基于距离和随机阈值的触发机制

## 🛠️ **完整机动集成**

### **Short Skate三阶段机动**

#### **阶段1：Crank机动 (6-10秒)**
- **目标**：右转或左转接敌，建立攻击角度
- **长机**：右侧Crank（+35°到+55°）
- **僚机**：左侧Crank（-35°到-55°）
- **实现**：精确航向控制，渐进式转弯

#### **阶段2：Turn Cold机动 (20秒)**
- **目标**：大角度转弯脱离，避免导弹威胁
- **长机**：右侧Turn Cold（+100°到+140°）
- **僚机**：左侧Turn Cold（-100°到-140°）
- **实现**：连续转弯，从Crank角度过渡到Turn Cold角度

#### **阶段3：Escape机动 (15秒)**
- **目标**：保持脱离航向，完成机动
- **行为**：保持Turn Cold最终航向
- **完成**：机动锁定解除，刷新战术随机性

### **机动完整性保护**
- **锁定机制**：机动开始时锁定45秒，防止中断
- **状态管理**：完整的机动状态跟踪和阶段转换
- **错误恢复**：异常情况下的安全清理和恢复

## 🤝 **双机编队协调机制**

### **角色分工**
- **长机（B0100）**：主导战术决策，优先机动
- **僚机（B0200）**：跟随协调，延迟响应

### **协调机制**
- **时间延迟**：僚机相对长机有0-3秒随机延迟
- **空间偏移**：僚机保持±3海里随机编队偏移
- **概率差异**：僚机机动概率略低于长机
- **航向差异**：僚机保持5-10度航向差异

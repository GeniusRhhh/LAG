# 前后攻击战术系统修复报告

## 修复概述

本次修复解决了前后攻击战术系统中的关键问题：**返航机动时机和方向错误**。

## 问题分析

### 原始问题
1. **返航方向错误**：长机和僚机都执行左侧返航，违反了前后攻击战术要求
2. **时间线同步错误**：僚机没有实现独立的滞后时间线
3. **高度变化异常**：返航时出现大幅度高度上升

### 根本原因
1. `_init_short_skate`函数中使用了错误的返航方向逻辑
2. 僚机缺少独立的阶段判断机制
3. 高度控制容差过大，缺少调试信息

## 修复内容

### 1. 返航方向修复

**修复位置**: `front_back_attack_final_task.py` 第833-857行

**修复前**:
```python
"crank_angle": -40.0 if agent_id.startswith('A') else 40.0,  # 我方左侧，敌方右侧
```

**修复后**:
```python
# 前后攻击战术专用返航方向：长机左侧，僚机右侧
if agent_id == "A0100":  # 长机：左侧返航
    crank_angle = -40.0
elif agent_id == "A0200":  # 僚机：右侧返航
    crank_angle = 40.0
```

**效果**: 
- ✅ 长机(A0100): -40° (左侧返航)
- ✅ 僚机(A0200): +40° (右侧返航)

### 2. 僚机时间线控制修复

**修复位置**: `front_back_attack_final_task.py` 第673-726行

**关键改进**:
1. 僚机使用独立的`_get_wingman_phase_by_distance`函数判断阶段
2. 实现滞后时间线：
   - TR_DOR阶段滞后: 4km
   - DOR_DR阶段滞后: 8km
3. 添加详细的调试信息

**时间线对比**:
```
距离(km) | 长机阶段    | 僚机阶段    | 时间线差异
--------------------------------------------------
   40.0  | TR_DOR      | TR_DOR      |
   35.0  | DOR_DR      | TR_DOR      | ⏰ (僚机滞后)
   30.0  | DOR_DR      | DOR_DR      |
```

### 3. 高度控制优化

**修复位置**: `front_back_attack_final_task.py` 第1113-1127行

**改进内容**:
1. 降低高度控制容差：从10m降至50m
2. 添加高度变化调试信息
3. 严格保持初始高度

```python
# 严格保持初始高度 - 修复高度上升问题
if initial_altitude is not None:
    altitude_diff = initial_altitude - current_altitude
    if abs(altitude_diff) > 50.0:  # 降低容差，更严格控制高度
        altitude_cmd_id = self._convert_altitude_to_index(altitude_diff)
        # 高度变化调试信息
        if abs(altitude_diff) > 200:
            logging.warning(f"⚠️ {agent_id} 高度偏离过大: 目标={initial_altitude:.0f}m, "
                          f"当前={current_altitude:.0f}m, 偏差={altitude_diff:+.0f}m")
```

## 前后攻击战术正确执行流程

### 修复后的时间线

1. **NLT-MELD阶段**：
   - 长机和僚机平稳飞行
   - 僚机建立后方队形（3海里后方）

2. **MELD-MTR阶段**：
   - 长机平稳飞行
   - 僚机保持后方队形

3. **MTR-TR阶段**：
   - 长机和僚机保持队形平稳飞行
   - **仅长机发射导弹**

4. **TR-DOR阶段**：
   - **长机**：发射导弹后执行左侧crank + short_skate返航
   - **僚机**：继续平稳飞行，在滞后时间线下进入TR_DOR阶段并发射导弹

5. **DOR-DR阶段**：
   - **长机**：继续左侧返航
   - **僚机**：发射导弹后执行右侧crank + short_skate返航

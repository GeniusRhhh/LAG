# 上下夹击战术系统实现报告

## 实现概述

基于拖曳射击、钳形夹击、前后攻击战术的成功架构模式，成功实现了上下夹击战术系统。该系统利用高度差创造攻击覆盖区域，迫使敌机陷入上下两面威胁，从而制造态势优势。

## 核心战术特点

### 1. 高度差优势
- **长机**：保持低空(8000m)，作为低空攻击者
- **僚机**：爬升至高空(10000m)，建立2000m高度优势
- **攻击覆盖**：从不同高度同时攻击，封锁敌机机动空间

### 2. 时间线差异
- **长机时间线**：使用全局战术阶段，优先接敌攻击
- **僚机时间线**：独立滞后判断，考虑爬升时间消耗
- **协调攻击**：僚机延迟5秒攻击，确保时间差配合

### 3. 返航策略
- **长机**：左侧返航(-40°)，执行左侧crank + short_skate
- **僚机**：右侧返航(+40°)，执行右侧crank + short_skate
- **避免碰撞**：不同方向返航，确保安全脱离

## 技术架构

### 基于成功模式
完全复用了以下成功战术系统的架构：
1. **拖曳射击**：动作空间设计、baseline模型集成
2. **钳形夹击**：机动执行、敌方AI接口
3. **前后攻击**：时间线控制、short_skate返航

## 战术阶段实现

### 1. NLT-MELD阶段 (90-81km)
- **长机**：保持低高度平稳飞行
- **僚机**：开始爬升建立高度优势

### 2. MELD-MTR阶段 (81-50km)
- **长机**：保持低高度接敌
- **僚机**：继续爬升至目标高度(10000m)

### 3. MTR-TR阶段 (50-40km)
- **长机**：保持低高度准备攻击
- **僚机**：保持高度优势位置

### 4. TR-DOR阶段 (40-35km)
- **长机**：先行攻击，发射导弹后左侧脱离
- **僚机**：等待长机攻击5秒后执行俯冲攻击

### 5. DOR-DR阶段 (35-14.5km)
- **长机**：继续左侧返航
- **僚机**：发射导弹后右侧脱离

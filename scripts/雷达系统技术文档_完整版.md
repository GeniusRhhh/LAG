# 3. 机载雷达探测与跟踪模型

## 3.1 机载雷达系统建模方法论

本项目中的空战仿真环境，要求机载雷达模型不仅能反映关键的技术特性，还需满足多智能体大规模实时对抗的计算效率需求。为此，本章基于俄制N001VE型和美制AN/APG-68(V)9型机载脉冲多普勒雷达的公开技术指标，建立了一个功能级的雷达探测与跟踪模型。

该模型的核心思想是，在保证战术对抗中宏观效果（如探测距离、角度覆盖、多普勒盲区效应、多目标处理能力等）真实性的前提下，对电磁波传播、信号处理等复杂的底层物理过程进行简化与等效。模型中的部分关键参数，如基础信噪比、大气衰减系数等，是在参考雷达手册数据的基础上，结合仿真需求进行合理估算与工程简化得到的。通过这种方法，实现了计算效率与战术真实性之间的高度平衡。

### 3.1.1 N001VE雷达系统（敌方Su-27/Su-30）

N001VE是苏联/俄罗斯第三代机载脉冲多普勒雷达，采用机械扫描天线，装备于Su-27和Su-30MKK战斗机。本模型采用统一的雷达资源管理架构，支持搜索（Search）、跟踪（Track）、锁定（Lock）三种基本工作模式。

对于雷达散射截面积（RCS）σ = 5.0 m²的典型战斗机目标（如F-16C），系统的核心性能参数设定如下：最大探测距离90 km（基于N001VE官方手册数据），最大稳定跟踪距离70 km，火控雷达锁定距离45 km，同时跟踪目标数10个（TWS模式），同时攻击目标数2个（支持R-27ER半主动雷达制导导弹）。

雷达波束宽度根据工作模式自适应调整：搜索模式下为±70°（总140°扫描范围）以实现广域扫描，跟踪模式下收窄至3°以集中能量维持目标航迹，锁定模式下则进一步聚焦至1°以提供精确的火控解算。由于采用机械扫描天线，雷达扫描周期T_scan = 3.5秒，显著慢于采用平板裂缝阵列的AN/APG-68(V)9（2.0秒），这是第三代与第四代雷达的典型代差。

雷达的电子反对抗（ECCM）能力为0.70，抗干扰能力为0.60，旁瓣抑制能力为0.85。天气影响因子为0.1，大气吸收系数为0.001（X波段）。基础探测概率为0.85，跟踪丢失概率为0.02，锁定丢失概率为0.01。

### 3.1.2 AN/APG-68(V)9雷达系统（友方F-16C Block 50/52）

AN/APG-68(V)9是美国诺斯罗普·格鲁曼公司为F-16C Block 50/52战斗机研制的第四代机载脉冲多普勒雷达，采用平板裂缝阵列天线（准相控阵），具有更快的扫描速度和更强的抗干扰能力。

对于σ = 5.0 m²的战斗机目标，系统核心性能参数如下：最大探测距离105 km（对5m² RCS目标），165 km（对大型目标如轰炸机）；最大跟踪距离85 km，火控锁定距离70 km（STT单目标跟踪模式）；同时跟踪目标数10个（TWS边跟踪边扫描模式），同时攻击目标数2个（支持AIM-120主动雷达制导导弹）。

雷达波束宽度：搜索模式±120°（宽覆盖），跟踪模式2.5°，锁定模式0.8°（高精度）。扫描周期T_scan = 2.0秒，比N001VE快43%，体现了准相控阵技术的优势。

APG-68(V)9具备优秀的下视/下射能力（Look-Down/Shoot-Down），地杂波抑制率达70%（DPCA技术），显著优于N001VE的40%。电子反对抗能力（ECCM）为0.82，抗干扰能力为0.75，旁瓣抑制能力为0.90，低截获概率能力为0.65，均优于N001VE。天气影响因子为0.08，大气吸收系数为0.0008（优化的X波段设计）。基础探测概率为0.90，跟踪丢失概率为0.015，锁定丢失概率为0.008。

## 3.2 雷达方程与信噪比模型

雷达探测的物理基础是信噪比（Signal-to-Noise Ratio, SNR），它量化了目标回波信号强度与背景噪声及干扰强度的对比关系，是决定目标能否被成功检测的根本依据。经典的雷达方程描述了接收功率P_r与雷达系统及目标特性的关系：

```
P_r = (P_t G² λ² σ) / ((4π)³ R⁴ L)     (3-1)
```

其中P_r为接收功率，P_t为发射功率，G为天线增益，λ为波长，σ为目标雷达截面积，R为距离，L为系统损耗。

上述经典雷达方程完整描述了雷达探测的物理机制，但在大规模多智能体实时仿真中，直接计算各项物理参数（如发射功率、天线增益、波长等）会显著增加计算负担。基于雷达方程的物理原理，本项目采用一个简化的对数域（分贝，dB）信噪比计算模型，将影响SNR的各项因素线性叠加，从而高效地评估探测性能：

```
SNR = SNR_base + SNR_distance + SNR_angle + SNR_atm     (3-2)
```

其中SNR为综合信噪比，SNR_base为基础信噪比，SNR_distance为距离衰减项，SNR_angle为角度衰减项，SNR_atm为大气损失项。

基础信噪比SNR_base根据雷达类型不同而不同：APG-68(V)9取42.0 dB，N001VE取40.0 dB。此值是基于雷达公开数据，对典型目标（σ = 5.0 m²）在参考距离（10 km）上进行标准大气条件下性能的工程估算，作为后续所有修正的基准。

**距离衰减项**基于经典雷达方程的R⁴衰减规律：

```
SNR_distance = -40 × log₁₀(R / 10000)     (3-3)
```

**角度衰减项**模拟了天线方向图的影响，即当目标偏离雷达波束中心时，天线增益下降导致SNR降低：

```
SNR_angle = -3 × |θ_b| / (θ_beam / 2)     (3-4)
```

其中θ_b为目标相对波束中心的偏离角，θ_beam为当前工作模式下的波束宽度。

**大气损失项**描述电磁波在大气中传播因吸收和散射而产生的损耗，该损耗与距离近似成正比：

```
SNR_atm = -0.1 × (R / 1000)     (3-5)
```

式中R为目标距离（米），损耗系数0.1 dB/km是针对X波段（8-12 GHz）在标准大气条件下的典型值。

需要说明的是，在当前功能级建模中，SNR主要用于数据记录和模型验证，探测概率计算采用距离分段模型（见3.3节），这是对"距离→SNR→探测概率"链路的工程等效。SNR与探测概率的理论对应关系为：SNR > 13 dB对应P_d > 0.9，SNR ≈ 10 dB对应P_d ≈ 0.7，SNR < 7 dB对应P_d < 0.3。这一对应关系可用于验证距离分段模型的物理合理性。

## 3.3 探测概率计算模型

探测概率P_d描述了在给定条件下，雷达系统成功判别出目标存在的概率。理论上，这取决于检测器的具体模型（如奈曼-皮尔逊准则）和设定的虚警概率P_fa。为简化计算并满足实时仿真需求，本项目采用基于距离分段的基础探测概率模型，结合多重物理效应修正因子的综合探测概率模型。

### 3.3.1 基础探测概率

基础探测概率P_base采用距离分段函数，根据雷达类型和探测距离确定。该模型直接将雷达探测性能与目标距离关联，是对完整雷达方程计算的工程简化。

对于N001VE雷达（最大探测距离90 km）：

```
P_base(N001VE) = {
    0.95,  if R ≤ 35 km    (对应SNR >15 dB)
    0.92,  if 35 km < R ≤ 55 km    (对应SNR ~13 dB)
    0.85,  if 55 km < R ≤ 70 km    (对应SNR ~10 dB)
    0.45,  if 70 km < R ≤ 80 km    (对应SNR ~5 dB)
    0.20,  if 80 km < R ≤ 90 km    (对应SNR ~3 dB)
    0.00,  if R > 90 km
}     (3-6a)
```

对于AN/APG-68(V)9雷达（最大探测距离105 km）：

```
P_base(APG-68) = {
    0.96,  if R ≤ 35 km    (对应SNR >15 dB)
    0.93,  if 35 km < R ≤ 60 km    (对应SNR ~13 dB)
    0.88,  if 60 km < R ≤ 85 km    (对应SNR ~10 dB)
    0.50,  if 85 km < R ≤ 95 km    (对应SNR ~5 dB)
    0.25,  if 95 km < R ≤ 105 km    (对应SNR ~3 dB)
    0.00,  if R > 105 km
}     (3-6b)
```

该分段模型设定了多个关键的距离阈值：近距离时探测概率接近1.0，随着距离增加逐渐降低，在最大探测距离附近探测概率显著下降，超过最大探测距离后归零。这些阈值的设定基于雷达手册数据和信噪比理论计算结果。

### 3.3.2 综合探测概率模型

基础探测概率仅反映了距离对探测性能的影响。在实际战场环境中，目标特性、环境条件、雷达工作状态等多种因素都会影响探测效果。因此，将这些物理因素作为修正因子，以乘性形式作用于P_base上，得到最终的综合探测概率P_d：

```
P_d = P_base · f_σ · f_φ · f_angle · f_notch · f_clutter · f_atm · f_w · f_bonus     (3-7)
```

各个修正因子的物理意义与计算模型如下：

#### （1）动态RCS修正因子 f_σ

目标雷达散射截面积（RCS）随视角动态变化，显著影响雷达回波强度。本模型基于目标姿态角计算动态RCS：

```
σ_dynamic = σ_baseline × f_horizontal × f_pitch × f_config     (3-8)
```

其中σ_baseline为基准RCS，特指**正面雷达散射截面积**。基于真实雷达测量数据：F-16C正面RCS取1.5 m²（真实测量范围1-2 m²，侧面8-15 m²），Su-27正面RCS取6.0 m²（真实测量范围5-8 m²，侧面25-35 m²）。水平视角因子f_horizontal描述目标水平姿态的影响：正面（0°）时取1.0（最小RCS），侧面（90°）时取2.5（最大RCS），尾部（180°）时取1.2（发动机喷口增加RCS）。具体计算公式为：

```
f_horizontal = {
    1.0 + 1.5 sin(α),      if 0° ≤ α ≤ 90°
    2.5 - 1.3 sin(α),      if 90° < α ≤ 180°
}     (3-9)
```

其中α为视角角度（相对目标机头方向）。

俯仰角因子f_pitch考虑目标腹部/背部的RCS增加：

```
f_pitch = 1.0 + 0.3 |sin(θ_pitch)|     (3-10)
```

配置因子f_config反映飞机气动构型的影响：低速（<150 m/s）时取1.4（减速板打开），正常速度时取1.2（武器挂架影响）。

计算出动态RCS后，采用对数形式归一化为修正因子。对数形式的采用是为了在σ值较小时，探测概率不会急剧下降，更符合真实雷达对不同RCS目标的探测特性：

```
f_σ(APG-68) = min(1.2, log₁₀(σ_dynamic + 1) / log₁₀(13))     (3-11a)
f_σ(N001VE) = min(1.15, log₁₀(σ_dynamic + 1) / log₁₀(7))     (3-11b)
```

APG-68对大RCS目标的探测能力更强，N001VE的归一化范围更窄。

#### （2）仰角修正因子 f_φ

仰角修正因子模拟了在不同仰角探测时的性能差异。低仰角探测时，地球表面反射可能带来多径效应或杂波影响，但通常低仰角探测性能更优。计算公式为：

```
f_φ(APG-68) = max(0.80, 1.0 - |φ| / 60°)     (3-12a)
f_φ(N001VE) = max(0.80, 1.0 - |φ| / 45°)     (3-12b)
```

其中φ为目标仰角（度）。APG-68的仰角覆盖范围更广（±60°），在大仰角情况下性能衰减更缓；N001VE的仰角覆盖较窄（±45°）。

#### （3）角度因子 f_angle

角度因子反映天线方向图对探测性能的影响。对于机械扫描雷达，在一个完整扫描周期内，天线能覆盖整个搜索范围，因此在探测概率计算中采用固定值：

```
f_angle = {
    0.92,  AN/APG-68(V)9
    0.90,  N001VE
}     (3-13)
```

APG-68的平板裂缝阵列天线具有更好的方向图特性，因此取值略高。

#### （4）多普勒盲区因子 f_notch

脉冲多普勒雷达通过滤波器滤除低多普勒频移的地面杂波，当目标径向速度过低时，会被误判为杂波而丢失。多普勒盲区因子根据径向速度v_r判定：

```
f_notch = {
    0.15,  if |v_r| < 50 m/s（APG-68，盲区内）
    0.08,  if |v_r| < 80 m/s（N001VE，盲区内）
    min(1.25, 1.0 + |v_r| / 400),  非盲区（APG-68）
    min(1.20, 1.0 + |v_r| / 450),  非盲区（N001VE）
}     (3-14)
```

其中v_r为径向速度（米/秒）。APG-68因杂波抑制能力更强，多普勒盲区更窄（50 m/s vs 80 m/s），且在盲区内保留更高的探测概率（15% vs 8%）。在非盲区情况下，高径向速度的目标产生显著的多普勒频移，有助于从背景杂波中提取信号，从而增强探测效果。N001VE对高速目标的探测增益略低（上限1.20 vs 1.25），且需要更高的径向速度才能获得同等的探测增益（450 m/s vs 400 m/s）。

#### （5）地面杂波因子 f_clutter

低空目标受地面杂波影响显著，雷达的杂波抑制能力决定了探测性能。地面杂波因子的计算考虑目标高度和雷达下视角：

```
f_clutter = {
    1.0,                                     if h > 100m 或 φ ≥ 0°
    1.0 - (0.3 + 0.5·f_h·f_φ)·(1 - η_sup),  otherwise
}     (3-15)
```

其中h为目标高度（米），f_h = (100 - h) / 100为高度因子，f_φ = |φ| / 45°为仰角因子。η_sup为杂波抑制能力：APG-68（DPCA技术）为0.70（抑制70%杂波），N001VE为0.40（抑制40%杂波）。最终杂波因子不低于0.1（保留10%探测概率）。

#### （6）大气衰减因子 f_atm

电磁波在大气中传播的衰减随距离增加而累积，大气衰减因子的计算公式为：

```
f_atm = max(0.8, 1.0 - (R / R_max) · κ_atm · 500)     (3-16)
```

其中κ_atm为大气吸收系数：APG-68为0.0008（优化的X波段设计），N001VE为0.001。R_max为各雷达的最大探测距离。

#### （7）天气修正因子 f_w

在标准气象条件下，天气修正因子取1.0。恶劣天气时（降雨、云层等），电磁波衰减增加：

```
f_w = {
    1.0 - 0.08 · I_weather,  APG-68
    1.0 - 0.10 · I_weather,  N001VE
}     (3-17)
```

其中I_weather为天气强度指标（0表示晴朗，1表示恶劣天气）。APG-68对恶劣天气的适应性更好。

#### （8）下视下射加成 f_bonus

APG-68(V)9具备优秀的下视/下射能力（Look-Down/Shoot-Down），在下视探测时性能有所加成：

```
f_bonus = {
    1.1,  if φ < -10° 且为APG-68
    1.0,  otherwise
}     (3-18)
```

当仰角小于-10°（向下看）且为APG-68雷达时，探测概率提升10%。

## 3.4 多普勒效应与盲区建模

脉冲多普勒雷达通过测量目标回波的多普勒频移f_d来区分运动目标与静止的地面杂波。多普勒频移的计算公式为：

```
f_d = 2 · f₀ · v_r / c     (3-19)
```

其中f₀ = 10 GHz为雷达工作频率（X波段），v_r为目标与雷达之间的径向速度分量，c为光速。径向速度分量计算为：

```
v_r = v⃗_target · (r⃗_radar - r⃗_target) / |r⃗_radar - r⃗_target|     (3-20)
```

其中v⃗_target为目标速度矢量，r⃗为位置矢量。

雷达的信号处理器只能检测到频移超出一定阈值的信号，从而滤除地面杂波。这就形成了多普勒盲区：

```
|v_r| > v_threshold = {
    50 m/s,  AN/APG-68(V)9
    80 m/s,  N001VE
}     (3-21)
```

当目标的径向速度低于此阈值时，雷达将暂时无法从杂波中分辨出目标。v_threshold的设定是模拟"Notch"和"Beam"等防御性机动的关键。

在空战中，常见的防御机动包括Notch机动（凹口机动）和Beam机动（横向规避）。Notch机动是指飞机通过快速机动并保持垂直于敌方雷达波束的飞行姿态，利用地面杂波遮蔽自身的战术机动。Beam机动是指飞机保持与敌方雷达波束垂直的飞行方向，最小化径向速度分量，从而进入多普勒盲区的机动。当目标通过机动使其与雷达的径向速度低于此阈值时（即进入波束"凹口"），雷达将暂时丢失目标，探测概率急剧下降至：

- APG-68：15%（优秀的杂波抑制保留部分探测能力）
- N001VE：8%（较差的杂波抑制）

这为战术决策中的生存与反击创造了机会，也是钳形夹击战术中僚机进行隐蔽机动、规避探测的物理基础。本模型通过实时计算径向速度并与雷达特定的v_threshold比较，准确模拟了Notch战术的效果。

## 3.5 电子对抗建模

电子对抗通过主动辐射或被动反射电磁能量，干扰敌方雷达的正常工作。在理论层面，噪声干扰（Jamming）通过在接收机端注入噪声功率P_j来直接降低信噪比：

```
SNR_jammed = P_r / (P_n + P_j)     (3-22)
```

其中P_r为接收功率，P_n为接收机固有噪声功率，P_j为干扰功率。

为简化计算并满足实时仿真需求，本项目将电子对抗等效为一个对最终探测概率的修正因子η_ECM：

```
P_d_jammed = P_d × η_ECM     (3-23)
```

模型中包含了噪声干扰、欺骗干扰、箔条干扰三种典型电子对抗措施（模拟战斗机机载自卫电子对抗系统，如ALQ-131吊舱）。不同干扰类型对不同雷达的影响系数如下：

| 干扰类型 | 对APG-68的影响 | 对N001VE的影响 | 物理原理 |
|---------|--------------|--------------|---------|
| 噪声干扰 | η = 0.50 | η = 0.30 | 在接收频段内注入宽带噪声 |
| 欺骗干扰 | η = 0.60 | η = 0.50 | 生成虚假目标或航迹 |
| 箔条干扰 | 未实现 | η = 0.20 | 抛撒金属箔条形成强反射 |

APG-68因具备更强的ECCM（电子反对抗）能力，受干扰影响更小。友方APG-68当前未实现箔条干扰响应，基于其优秀的抗干扰能力和ECCM技术。敌方N001VE实现了完整的三种ECM响应。

雷达的ECCM能力通过以下技术实现：频率捷变（快速跳频避开干扰频段，APG-68和N001VE均支持），旁瓣抑制（APG-68为0.90，N001VE为0.85），低截获概率（LPI，APG-68为0.65，N001VE无）。综合ECCM能力：APG-68为0.82，N001VE为0.70。

电子对抗措施的激活采用**威胁驱动激活机制**，基于RWR（雷达告警接收机）探测到的威胁等级智能激活。激活概率与威胁等级正相关：
- **威胁等级≥3（被锁定或导弹威胁）**：友方APG-68以80%概率激活ECM，敌方N001VE以90%概率激活（因ECCM能力较弱，更依赖ECM防御）
- **威胁等级=2（被跟踪）**：友方30%概率，敌方40%概率激活
- **威胁等级=1（被搜索）**：友方5%概率，敌方10%概率预防性激活
- **威胁等级=0（无威胁）**：不激活ECM

这种威胁驱动机制符合真实空战中ECM的使用策略：在高威胁情况下立即激活，避免在安全时浪费ECM资源或暴露电子特征。ECM激活后持续5-15秒的均匀分布时间。模型同时考虑了雷达具备的频率捷变能力，设定了抗干扰系数：

```
η_resist = {
    0.75,  AN/APG-68(V)9
    0.60,  N001VE
}     (3-24)
```

## 3.6 目标跟踪与锁定逻辑

雷达系统采用多阶段工作模式以高效管理探测资源：

- **搜索模式（Search）**：广域扫描，用于发现新目标。
- **跟踪模式（Track，TWS）**：集中能量，用于维持已发现目标的精确航迹。
- **锁定模式（Lock，STT）**：波束最窄，为武器系统提供高精度的制导信息。

模式之间的转换由目标距离R和跟踪质量Q_track共同决定。对于友方APG-68雷达：

```
Mode(APG-68) = {
    LOCK,    if R ≤ 70 km ∧ Q_track > 0.5
    TRACK,   if R ≤ 85 km ∧ Q_track > 0.3
    SEARCH,  otherwise
}     (3-25a)
```

对于敌方N001VE雷达：

```
Mode(N001VE) = {
    LOCK,    if R ≤ 45 km ∧ Q_track > 0.6
    TRACK,   if R ≤ 70 km ∧ Q_track > 0.3
    SEARCH,  otherwise
}     (3-25b)
```

跟踪质量Q_track是一个综合指标，其物理含义是目标航迹的稳定性和可信度，由距离因子、时间因子和机动因子共同决定：

```
Q_track = f_distance × (1.0 - f_time) / f_maneuver     (3-26)
```

其中距离因子f_distance = max(0.1, 1.0 - R / R_track)，R_track为最大跟踪距离（APG-68为85 km，N001VE为70 km）。时间因子f_time = min(1.0, Δt / T_update)，其中Δt为距离上次更新的时间间隔，T_update为跟踪更新周期（APG-68为4.0秒，N001VE为5.0秒）。

机动因子f_maneuver考虑高机动目标更难跟踪的特性，基于目标滚转角φ_roll计算：

```
f_maneuver = {
    1.0 + 0.5 × (|φ_roll| / 90°),  APG-68（最大2.0）
    1.0 + 0.8 × (|φ_roll| / 90°),  N001VE（最大2.5）
}     (3-27)
```

N001VE对机动目标更敏感，跟踪丢失概率更高。

在多目标环境下，雷达需要对不同威胁进行优先级排序。目标优先级P_priority基于距离和跟踪质量综合计算：

```
P_priority = (1.0 / max(R, 1000)) × Q_track     (3-28)
```

距离最近且跟踪质量最高的目标将被优先锁定。为避免因信号起伏导致工作模式在临界状态频繁跳变（抖动），系统要求连续满足转换条件后，才最终确认状态的转换。

跟踪质量的动态变化和多目标优先级的计算，是实现"拖曳射击"和"并排射击"等协同战术的核心。在本项目的2v2空战仿真中，实现了拖曳射击（Drag Shoot）和并排射击（Side by Side Shooting）两种典型协同战术。拖曳射击是指长机和僚机采用时间差发射导弹，长机先发射后执行Short Skate机动撤离，僚机在稍后时刻发射并掩护长机，形成连续威胁；并排射击是指长机和僚机保持横向间隔的并排队形，在接近最佳发射距离时同时发射导弹，形成饱和攻击。雷达系统决定了火控系统何时能够提供满足武器发射条件的精确制导信息，并如何在多个威胁目标之间进行高效的火力分配。

## 3.7 RWR与导弹发射集成

### 3.7.1 RWR系统建模

雷达告警接收机（Radar Warning Receiver, RWR）是现代战斗机的重要电子战设备，用于被动探测和识别敌方雷达辐射，为飞行员提供威胁告警。RWR系统将探测到的雷达威胁分为6个等级：

```
L_threat = {
    0: 无威胁
    1: 搜索模式照射（SEARCH）
    2: 跟踪模式照射（TRACK，TWS）
    3: 锁定模式照射（LOCK，STT）
    4: 检测到导弹发射
    5: 检测到导弹制导雷达
}     (3-29)
```

RWR不仅提供威胁等级，还能测定威胁源的方位角θ_threat = arctan2(Δx, Δy)，其中(Δx, Δy)为威胁源相对本机的水平位置差。本模型实现了双向对称的RWR系统，友方和敌方均能探测对方雷达辐射，用于自动触发ECM、战术机动决策和火力分配优化。

### 3.7.2 导弹发射集成检查

为确保导弹发射的战术合理性，本模型实现了完整的雷达-武器集成检查逻辑。导弹发射前需满足以下条件：

1. 目标在雷达跟踪列表中（target_id ∈ tracked_targets）
2. 雷达处于TRACK或LOCK模式（Mode ≥ TRACK）
3. 跟踪质量达到最低要求（Q_track ≥ 0.3）
4. 目标在最大跟踪距离内（R ≤ R_track）
5. 目标不在多普勒盲区（|v_r| > v_threshold）
6. 探测概率达到基本要求（P_d ≥ 0.2）

不同导弹对雷达状态要求不同：R-27ER半主动雷达制导导弹要求发射机雷达持续锁定目标（STT模式），直至导弹命中；AIM-120主动雷达制导导弹只需TWS模式提供中段数据链更新，末段由导弹自主制导。

## 3.8 概率性探测机制

为模拟真实雷达探测过程中的随机不确定性，本模型采用概率性探测机制。对于计算得到的综合探测概率P_d，通过与一个[0,1]区间内均匀分布的随机数ξ进行比较，来判定本次扫描是否成功探测到目标：

```
Detection = {
    Success,  if ξ < P_d
    Failure,  if ξ ≥ P_d
}     (3-30)
```

这种机制使得对远距离、低RCS或受干扰目标的探测不再是一个确定性的过程，而是需要多次扫描尝试才能建立稳定航迹，这与真实战场环境更为贴近，也为战术仿真增加了更多的不确定性与博弈性。

## 3.9 模型总结与验证

方程(3-1)至(3-30)构成了完整的功能级雷达探测与跟踪模型。该模型建立了从目标参数获取、探测概率计算到雷达状态管理的完整计算链路。

模型同时实现APG-68(V)9和N001VE两型雷达，体现第四代与第三代雷达的技术代差。基于真实雷达手册参数，包括探测距离、扫描周期、波束宽度等。涵盖动态RCS、多普勒盲区、地面杂波、RWR、ECM/ECCM等战术要素。通过简化底层物理过程，适合大规模多智能体实时仿真，统一的API接口支持多种战术模板复用。

模型参数与真实雷达手册数据对比验证结果如下：

| 参数 | APG-68手册值 | 模型值 | 误差 | N001VE手册值 | 模型值 | 误差 |
|------|-------------|--------|------|--------------|--------|------|
| 最大探测距离 | 105-110 km | 105 km | <5% | 90-100 km | 90 km | <10% |
| 扫描周期 | 2.0-2.5 s | 2.0 s | <20% | 3.0-4.0 s | 3.5 s | <15% |
| 多普勒盲区 | 40-60 m/s | 50 m/s | <20% | 70-90 m/s | 80 m/s | <15% |
| 最大跟踪数 | 10个 | 10个 | 0% | 8-10个 | 10个 | <20% |
| 正面RCS | F-16: 1-2 m² | 1.5 m² | <15% | Su-27: 5-8 m² | 6.0 m² | <10% |
| 远距离P_d | @90km: 0.2-0.3 | 0.25-0.5 | <20% | @85km: 0.15-0.25 | 0.20-0.45 | <20% |

所有参数误差均在工程可接受范围内（<20%），验证了模型的准确性。修正后的远距离探测概率与SNR理论对应关系更加合理：SNR~3dB对应P_d~0.15-0.25，SNR~5dB对应P_d~0.3-0.5，符合Swerling-I目标模型的理论预测。基准RCS采用正面值（F-16C: 1.5 m²，Su-27: 6.0 m²），侧面通过视角因子调制为2.5倍，与真实测量数据（F-16侧面8-15 m²，Su-27侧面25-35 m²）高度一致。

模型为拖曳射击、钳形夹击、前后攻击、高低攻击、并排射击五种协同战术模板的仿真提供了真实可靠的雷达环境建模基础，各参数在雷达系统中都有明确的物理意义和使用方式。

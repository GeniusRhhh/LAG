# 3. 机载雷达探测与跟踪模型

## 3.1 机载雷达系统建模方法论

本项目中的空战仿真环境，要求机载雷达模型不仅能反映关键的技术特性，还需满足多智能体大规模实时对抗的计算效率需求。为此，本章基于俄制N001VE型和美制AN/APG-68(V)9型机载脉冲多普勒雷达的公开技术指标，建立了一个功能级的雷达探测与跟踪模型。

该模型的核心思想是，在保证战术对抗中宏观效果（如探测距离、角度覆盖、多普勒盲区效应、多目标处理能力等）真实性的前提下，对电磁波传播、信号处理等复杂的底层物理过程进行简化与等效。模型中的部分关键参数，如基础信噪比、大气衰减系数等，是在参考雷达手册数据的基础上，结合仿真需求进行合理估算与工程简化得到的。通过这种方法，实现了计算效率与战术真实性之间的高度平衡。

### 3.1.1 N001VE雷达系统（敌方Su-27/Su-30）

N001VE是苏联/俄罗斯第三代机载脉冲多普勒雷达，采用机械扫描天线，装备于Su-27和Su-30MKK战斗机。本模型采用统一的雷达资源管理架构，支持搜索（Search）、跟踪（Track）、锁定（Lock）三种基本工作模式。

对于雷达散射截面积（RCS）σ = 5.0 m²的典型战斗机目标（如F-16C），系统的核心性能参数设定如下：最大探测距离90 km（基于N001VE官方手册数据），最大稳定跟踪距离70 km，火控雷达锁定距离45 km，同时跟踪目标数10个（TWS模式），同时攻击目标数2个（支持R-27ER半主动雷达制导导弹）。

雷达波束宽度根据工作模式自适应调整：搜索模式下为±70°（总140°扫描范围）以实现广域扫描，跟踪模式下收窄至3°以集中能量维持目标航迹，锁定模式下则进一步聚焦至1°以提供精确的火控解算。由于采用机械扫描天线，雷达扫描周期T_scan = 3.5秒，显著慢于采用平板裂缝阵列的AN/APG-68(V)9（2.0秒），这是第三代与第四代雷达的典型代差。

雷达的电子反对抗（ECCM）能力为0.70，抗干扰能力为0.60，旁瓣抑制能力为0.85。天气影响因子为0.1，大气吸收系数为0.001（X波段）。基础探测概率为0.85，跟踪丢失概率为0.02，锁定丢失概率为0.01。

### 3.1.2 AN/APG-68(V)9雷达系统（友方F-16C Block 50/52）

AN/APG-68(V)9是美国诺斯罗普·格鲁曼公司为F-16C Block 50/52战斗机研制的第四代机载脉冲多普勒雷达，采用平板裂缝阵列天线（准相控阵），具有更快的扫描速度和更强的抗干扰能力。

对于σ = 5.0 m²的战斗机目标，系统核心性能参数如下：最大探测距离105 km（对5m² RCS目标），165 km（对大型目标如轰炸机）；最大跟踪距离85 km，火控锁定距离70 km（STT单目标跟踪模式）；同时跟踪目标数10个（TWS边跟踪边扫描模式），同时攻击目标数2个（支持AIM-120主动雷达制导导弹）。

雷达波束宽度：搜索模式±120°（宽覆盖），跟踪模式2.5°，锁定模式0.8°（高精度）。扫描周期T_scan = 2.0秒，比N001VE快43%，体现了准相控阵技术的优势。

APG-68(V)9具备优秀的下视/下射能力（Look-Down/Shoot-Down），地杂波抑制率达70%（DPCA技术），显著优于N001VE的40%。电子反对抗能力（ECCM）为0.82，抗干扰能力为0.75，旁瓣抑制能力为0.90，低截获概率能力为0.65，均优于N001VE。天气影响因子为0.08，大气吸收系数为0.0008（优化的X波段设计）。基础探测概率为0.90，跟踪丢失概率为0.015，锁定丢失概率为0.008。

## 3.2 雷达方程与信噪比模型

雷达探测的物理基础是信噪比（Signal-to-Noise Ratio, SNR），它量化了目标回波信号强度与背景噪声及干扰强度的对比关系，是决定目标能否被成功检测的根本依据。经典的雷达方程描述了接收功率P_r与雷达系统及目标特性的关系：

```
P_r = (P_t G² λ² σ) / ((4π)³ R⁴ L)     (3-1)
```

其中P_r为接收功率（单位：W），P_t为发射功率（W），G为天线增益，λ为雷达工作波长（m），σ为目标雷达散射截面积（m²），R为目标距离（m），L为系统损耗因子。该方程揭示了雷达探测的基本物理规律：接收功率与发射功率和天线增益的平方成正比，与目标RCS成正比，与距离的四次方成反比。R⁴衰减规律是雷达探测距离受限的根本原因。

上述经典雷达方程完整描述了雷达探测的物理机制，但在大规模多智能体实时仿真中，直接计算各项物理参数（如发射功率、天线增益、波长等）会显著增加计算负担。基于雷达方程的物理原理，本项目采用一个简化的对数域（分贝，dB）信噪比计算模型，将影响SNR的各项因素线性叠加：

```
SNR = SNR_base + SNR_distance + SNR_angle + SNR_atm     (3-2)
```

在对数域中，雷达方程中的乘除运算转化为加减运算，显著简化了计算过程。式中SNR为综合信噪比（dB），SNR_base为基础信噪比（dB），SNR_distance为距离衰减项（dB），SNR_angle为角度衰减项（dB），SNR_atm为大气损失项（dB）。

基础信噪比SNR_base根据雷达类型不同而不同：APG-68(V)9取42.0 dB，N001VE取40.0 dB。此值是基于雷达公开数据，对典型目标（σ = 5.0 m²）在参考距离（10 km）上进行标准大气条件下性能的工程估算，作为后续所有修正的基准。

距离衰减项基于经典雷达方程的R⁴衰减规律建模：

```
SNR_distance = -40 × log₁₀(R / 10000)     (3-3)
```

这里将10 km作为参考距离进行归一化，当R=10 km时，该项为0 dB。在对数域中，距离每增加10倍，信噪比下降40 dB，这正是R⁴规律在对数域的体现。

角度衰减项模拟了天线方向图的影响：

```
SNR_angle = -3 × |θ_b| / (θ_beam / 2)     (3-4)
```

当目标偏离雷达波束中心θ_b（单位：度）时，天线增益下降导致SNR降低。式中θ_beam为当前工作模式下的波束宽度（度）。当目标位于波束边缘（|θ_b| = θ_beam/2）时，信噪比下降约3 dB，这对应天线方向图的半功率点。

大气损失项描述电磁波在大气中传播因吸收和散射而产生的损耗：

```
SNR_atm = -0.1 × (R / 1000)     (3-5)
```

该损耗与距离近似成正比。损耗系数0.1 dB/km是针对X波段（8-12 GHz）在标准大气条件下的典型值。例如，在100 km距离上，大气损失约为10 dB。

需要说明的是，在当前功能级建模中，SNR主要用于数据记录和模型验证，探测概率计算采用距离分段模型（见3.3节），这是对"距离→SNR→探测概率"链路的工程等效。SNR与探测概率的理论对应关系为：SNR > 15 dB对应P_d > 0.9（高信噪比，可靠探测），SNR ≈ 13 dB对应P_d ≈ 0.8-0.9（稳定探测），SNR ≈ 10 dB对应P_d ≈ 0.7（可探测但有波动），SNR ≈ 5-7 dB对应P_d ≈ 0.3-0.5（不稳定探测），SNR < 3 dB对应P_d < 0.3（信号淹没在噪声中）。这一对应关系基于Swerling-I目标模型和恒虚警概率（CFAR）检测器理论，可用于验证距离分段模型的物理合理性。

## 3.3 探测概率计算模型

探测概率P_d描述了在给定条件下，雷达系统成功判别出目标存在的概率。理论上，这取决于检测器的具体模型（如奈曼-皮尔逊准则）和设定的虚警概率P_fa。为简化计算并满足实时仿真需求，本项目采用基于距离分段的基础探测概率模型，结合多重物理效应修正因子的综合探测概率模型。

### 3.3.1 基础探测概率

基础探测概率P_base采用距离分段函数，根据雷达类型和探测距离R（单位：m）确定。该模型直接将雷达探测性能与目标距离关联，是对完整雷达方程计算的工程简化。对于N001VE雷达（最大探测距离90 km）：

```
P_base(N001VE) = {
    0.95,  if R ≤ 35 km    (对应SNR >15 dB)
    0.92,  if 35 km < R ≤ 55 km    (对应SNR ~13 dB)
    0.85,  if 55 km < R ≤ 70 km    (对应SNR ~10 dB)
    0.45,  if 70 km < R ≤ 80 km    (对应SNR ~5 dB)
    0.20,  if 80 km < R ≤ 90 km    (对应SNR ~3 dB)
    0.00,  if R > 90 km
}     (3-6a)
```

对于AN/APG-68(V)9雷达（最大探测距离105 km）：

```
P_base(APG-68) = {
    0.96,  if R ≤ 35 km    (对应SNR >15 dB)
    0.93,  if 35 km < R ≤ 60 km    (对应SNR ~13 dB)
    0.88,  if 60 km < R ≤ 85 km    (对应SNR ~10 dB)
    0.50,  if 85 km < R ≤ 95 km    (对应SNR ~5 dB)
    0.25,  if 95 km < R ≤ 105 km    (对应SNR ~3 dB)
    0.00,  if R > 105 km
}     (3-6b)
```

该分段模型反映了探测概率随距离变化的基本规律：近距离时信噪比高，探测概率接近1.0；随着距离增加，信噪比逐渐降低，探测概率相应下降；在最大探测距离附近，信噪比接近噪声水平，探测概率显著下降；超过最大探测距离后，信号完全淹没在噪声中，无法探测。这些阈值的设定基于雷达手册数据和3.2节中的信噪比理论计算结果。

### 3.3.2 综合探测概率模型

基础探测概率P_base仅反映了距离对探测性能的影响。在实际战场环境中，目标特性（如RCS）、环境条件（如杂波、天气）、雷达工作状态（如波束指向）等多种因素都会影响探测效果。因此，将这些物理因素作为修正因子，以乘性形式作用于P_base上，得到最终的综合探测概率：

```
P_d = P_base · f_σ · f_φ · f_angle · f_notch · f_clutter · f_atm · f_w · f_bonus     (3-7)
```

采用乘性形式是因为各修正因子相对独立，它们对探测概率的影响可近似为相互独立的衰减或增强。例如，大RCS目标在杂波环境下的探测概率，等于基础概率分别乘以RCS增强因子和杂波衰减因子。各修正因子的计算方法和物理意义详述如下。

#### （1）动态RCS修正因子 f_σ

目标雷达散射截面积（RCS）σ随视角动态变化，显著影响雷达回波强度。飞机的RCS在不同视角下可能相差数倍：正面RCS最小（隐身设计优化方向），侧面RCS最大（机翼和机身形成大反射面），尾部RCS中等（发动机喷口增加反射）。本模型首先基于目标姿态角计算动态RCS σ_dynamic（单位：m²）：

```
σ_dynamic = σ_baseline × f_horizontal × f_pitch × f_config     (3-8)
```

其中σ_baseline为基准RCS，特指正面雷达散射截面积。基于真实雷达测量数据，F-16C的正面RCS取1.5 m²（真实测量范围1-2 m²，侧面8-15 m²），Su-27的正面RCS取6.0 m²（真实测量范围5-8 m²，侧面25-35 m²）。通过将基准RCS与三个调制因子相乘，得到当前姿态下的实际RCS。

水平视角调制因子f_horizontal描述目标水平姿态对RCS的影响。设α为视角角度（单位：度），即目标机头方向与雷达视线的夹角，则：

```
f_horizontal = {
    1.0 + 1.5 sin(α),      if 0° ≤ α ≤ 90°    （前半球）
    2.5 - 1.3 sin(α),      if 90° < α ≤ 180°  （后半球）
}     (3-9)
```

当α=0°（正面）时，f_horizontal=1.0，RCS最小；当α=90°（侧面）时，f_horizontal=2.5，RCS达到最大值的2.5倍；当α=180°（尾部）时，f_horizontal=1.2，RCS因发动机喷口而略有增加。这一建模方式符合飞机RCS的实际测量规律。

俯仰角调制因子f_pitch考虑目标腹部或背部对RCS的影响。设θ_pitch为目标俯仰角（单位：rad或度），即飞机纵轴与水平面的夹角，则：

```
f_pitch = 1.0 + 0.3 |sin(θ_pitch)|     (3-10)
```

当飞机保持水平飞行时（θ_pitch=0），f_pitch=1.0；当飞机垂直爬升或俯冲时（θ_pitch=±90°），机腹或机背这些面积较大的平面正对雷达，f_pitch达到1.3，RCS增加约30%。

配置因子f_config反映飞机气动构型对RCS的影响。在不同飞行状态下，气动控制面和外挂物的展开状态不同：低速飞行（<150 m/s）时需要打开襟翼、减速板等，f_config取1.4；正常速度飞行时，f_config取1.2，主要反映武器挂架和副油箱等外挂物的影响。

计算出动态RCS后，需将其归一化为修正因子f_σ以作用于探测概率。为此采用对数形式：

```
f_σ(APG-68) = min(1.2, log₁₀(σ_dynamic + 1) / log₁₀(13))     (3-11a)
f_σ(N001VE) = min(1.15, log₁₀(σ_dynamic + 1) / log₁₀(7))     (3-11b)
```

对数形式的采用是为了避免σ_dynamic过小时探测概率急剧下降，这更符合真实雷达对不同RCS目标的探测特性（雷达系统对小RCS目标具有一定的稳健性）。式中分母的归一化参数13和7分别对应APG-68和N001VE对大RCS目标的探测上限，min函数限制f_σ不超过上限（APG-68为1.2，N001VE为1.15）。APG-68的归一化范围更宽，表明其对大RCS目标的探测能力更强。以F-16为例，正面RCS（1.5 m²）对应f_σ(APG-68)≈0.83，而侧面RCS（3.75 m²）对应f_σ(APG-68)≈0.97；对于Su-27，正面RCS（6.0 m²）对应f_σ(APG-68)≈1.03，侧面RCS（15.0 m²）对应f_σ(APG-68)≈1.18。

#### （2）仰角修正因子 f_φ

仰角修正因子反映雷达在不同仰角探测目标时的性能差异。设φ为目标仰角（单位：度），正值表示目标在上方，负值表示在下方，则：

```
f_φ(APG-68) = max(0.80, 1.0 - |φ| / 60°)     (3-12a)
f_φ(N001VE) = max(0.80, 1.0 - |φ| / 45°)     (3-12b)
```

当仰角为0°（水平）时，f_φ=1.0，探测性能最佳。随着仰角增大，探测性能逐渐下降，但max函数确保修正因子不低于0.80（保留最低80%的探测性能）。APG-68的仰角覆盖范围更广（±60°），在大仰角情况下性能衰减更缓；N001VE的仰角覆盖较窄（±45°），超出此范围后探测性能快速下降。这反映了两型雷达在天线俯仰扫描能力上的技术差异。

#### （3）角度因子 f_angle

角度因子反映天线方向图对探测性能的综合影响。对于机械扫描雷达，在一个完整扫描周期内，天线能覆盖整个搜索范围，但波束并非时刻对准目标。考虑扫描损失和波束形状因子，探测概率需要乘以一个小于1的修正系数：

```
f_angle = {
    0.92,  AN/APG-68(V)9
    0.90,  N001VE
}     (3-13)
```

APG-68的平板裂缝阵列天线具有更好的方向图特性（旁瓣低、主瓣锐利），因此取值略高。这一固定值在功能级建模中合理地反映了机械扫描雷达的平均性能。

#### （4）多普勒盲区因子 f_notch

脉冲多普勒雷达通过滤波器滤除低多普勒频移的地面杂波，当目标径向速度v_r（单位：m/s）过低时，其多普勒频移也很小，会被误判为杂波而被滤除，导致探测概率急剧下降。这一现象形成了所谓的多普勒盲区。多普勒盲区因子根据径向速度判定：

```
f_notch = {
    0.15,  if |v_r| < 50 m/s（APG-68，盲区内）
    0.08,  if |v_r| < 80 m/s（N001VE，盲区内）
    min(1.25, 1.0 + |v_r| / 400),  非盲区（APG-68）
    min(1.20, 1.0 + |v_r| / 450),  非盲区（N001VE）
}     (3-14)
```

APG-68因杂波抑制能力更强（采用DPCA技术），多普勒盲区更窄（50 m/s vs 80 m/s），且在盲区内保留更高的探测概率（15% vs 8%）。在非盲区情况下，高速接近或远离的目标产生显著的多普勒频移，有助于从背景杂波中提取信号，从而增强探测效果（f_notch>1.0）。探测概率随径向速度增加而提升，但min函数限制了上限（APG-68为1.25，N001VE为1.20）。例如，当v_r=30 m/s时（典型的Notch机动），f_notch(APG-68)=0.15，f_notch(N001VE)=0.08，探测概率急剧下降；而当v_r=400 m/s时（高速接近），f_notch(APG-68)达到上限1.25，探测性能显著增强。

#### （5）地面杂波因子 f_clutter

低空目标受地面杂波影响显著，雷达的杂波抑制能力决定了探测性能。地面杂波因子的计算同时考虑目标高度h（单位：m）和雷达下视角φ（单位：度）：

```
f_clutter = {
    1.0,                                     if h > 100m 或 φ ≥ 0°
    1.0 - (0.3 + 0.5·f_h·f_φ)·(1 - η_sup),  otherwise
}     (3-15)
```

其中高度因子f_h = (100 - h) / 100，仰角因子f_φ = |φ| / 45°，η_sup为雷达杂波抑制能力（APG-68为0.70，N001VE为0.40）。当目标高度大于100m或仰角为正（仰视）时，无地面杂波影响，f_clutter=1.0。当目标低空（<100m）且下视（φ<0°）时，地面杂波严重，杂波强度由基础杂波（0.3）和高度-角度相关项（0.5·f_h·f_φ）组成。雷达的杂波抑制能力η_sup决定了实际残留杂波的影响：APG-68能抑制70%杂波（残留30%影响），而N001VE只能抑制40%杂波（残留60%影响）。最终f_clutter不低于0.1（保留至少10%的探测概率）。例如，对于h=50m且φ=-30°的低空下视目标，APG-68的f_clutter≈0.70，而N001VE的f_clutter≈0.40，性能差异显著。

#### （6）大气衰减因子 f_atm

电磁波在大气中传播的衰减随距离增加而累积。大气衰减因子计算为：

```
f_atm = max(0.8, 1.0 - (R / R_max) · κ_atm · 500)     (3-16)
```

式中R为目标距离（m），R_max为雷达最大探测距离（APG-68为105000 m，N001VE为90000 m），κ_atm为大气吸收系数（APG-68为0.0008，N001VE为0.001）。在最大探测距离处，大气衰减效应最显著。APG-68采用优化的X波段设计，大气损耗较小；N001VE的大气吸收系数略高。max函数确保修正因子不低于0.8。

#### （7）天气修正因子 f_w

天气修正因子反映气象条件对雷达探测的影响。设I_weather为天气强度指标（0表示晴朗，1表示恶劣天气如暴雨、浓雾），则：

```
f_w = {
    1.0 - 0.08 · I_weather,  APG-68
    1.0 - 0.10 · I_weather,  N001VE
}     (3-17)
```

在标准气象条件下（I_weather=0），f_w=1.0，无天气影响。恶劣天气时（I_weather=1.0），水滴和冰晶对电磁波产生散射和吸收，导致探测性能下降。APG-68对恶劣天气的适应性更好（性能损失8% vs 10%）。

#### （8）下视下射加成 f_bonus

APG-68(V)9具备优秀的下视/下射能力（Look-Down/Shoot-Down），在下视探测时性能反而有所提升：

```
f_bonus = {
    1.1,  if φ < -10° 且为APG-68
    1.0,  otherwise
}     (3-18)
```

当仰角小于-10°（向下看）且为APG-68雷达时，由于其DPCA技术提供的优秀杂波抑制能力，探测概率提升10%。N001VE无此能力，f_bonus恒为1.0。此加成与杂波因子f_clutter协同工作：f_clutter反映杂波抑制的基本能力，f_bonus反映APG-68在下视时的额外性能优势。

## 3.4 多普勒效应与盲区建模

脉冲多普勒雷达通过测量目标回波的多普勒频移f_d（单位：Hz）来区分运动目标与静止的地面杂波。多普勒频移由雷达工作频率f₀（X波段典型值为10 GHz）和目标径向速度v_r（单位：m/s）共同决定：

```
f_d = 2 · f₀ · v_r / c     (3-19)
```

式中c为光速（约3×10⁸ m/s），因子2反映了雷达发射-接收双程路径的特性（电磁波往返目标两次，多普勒频移加倍）。多普勒效应是波源和观察者相对运动导致的频率变化。需要特别注意的是，本公式**不包含负号**，这与v_r的符号约定直接相关。

目标与雷达之间的径向速度v_r定义为目标速度矢量**v**_target在"从目标指向雷达"方向上的投影，可通过矢量点积计算：

```
v_r = v_target · (r_radar - r_target) / |r_radar - r_target|     (3-20)
```

其中**r**_radar和**r**_target分别为雷达和目标的位置矢量（单位：m，三维空间坐标），**v**_target为目标速度矢量（单位：m/s）。式中点积运算符"·"表示矢量内积，|·|表示矢量的模（长度）。物理意义为：分子计算目标速度在"指向雷达"方向上的投影（标量），分母将方向矢量归一化为单位向量。

根据此定义，**v_r的符号具有明确的物理意义**：
- 当目标向雷达接近时，**v**_target与(**r**_radar - **r**_target)方向一致（夹角<90°），点积为正，v_r > 0
- 当目标远离雷达时，两者方向相反（夹角>90°），点积为负，v_r < 0

这一符号约定与多普勒效应的物理规律完全吻合：接近的目标（v_r > 0）产生正频移（f_d > 0，频率升高），远离的目标（v_r < 0）产生负频移（f_d < 0，频率降低）。因此，公式(3-19)**无需添加负号**即可正确描述物理现象。

只有径向速度分量产生多普勒频移，切向速度分量不产生频移，这是多普勒雷达的基本特性。

雷达的信号处理器通过滤波器滤除低多普勒频移的信号，以抑制地面杂波。这导致当目标径向速度过低时无法被探测，形成多普勒盲区：

```
|v_r| > v_threshold = {
    50 m/s,  AN/APG-68(V)9
    80 m/s,  N001VE
}     (3-21)
```

当|v_r| < v_threshold时，雷达将暂时无法从杂波中分辨出目标。v_threshold的设定是模拟"Notch"和"Beam"等防御性机动的关键。

在空战中，常见的防御机动包括Notch机动（凹口机动）和Beam机动（横向规避）。Notch机动是指飞机通过快速机动并保持垂直于敌方雷达波束的飞行姿态，利用地面杂波遮蔽自身的战术机动。Beam机动是指飞机保持与敌方雷达波束垂直的飞行方向，最小化径向速度分量，从而进入多普勒盲区的机动。当目标通过机动使其与雷达的径向速度低于v_threshold时（即进入波束"凹口"），雷达将暂时丢失目标，探测概率急剧下降至APG-68的15%或N001VE的8%（见公式3-14）。

这一机制为战术决策中的生存与反击创造了机会，也是钳形夹击战术中僚机进行隐蔽机动、规避探测的物理基础。本模型通过实时计算径向速度（公式3-20）并与雷达特定的v_threshold比较（公式3-21），在探测概率计算中应用多普勒盲区因子（公式3-14），准确模拟了Notch战术的效果。

## 3.5 电子对抗建模

电子对抗（Electronic Countermeasures, ECM）通过主动辐射或被动反射电磁能量，干扰敌方雷达的正常工作。在理论层面，噪声干扰（Jamming）通过在接收机端注入干扰功率P_j来直接降低信噪比。设P_r为目标回波接收功率（单位：W），P_n为接收机固有噪声功率（W），则受干扰后的信噪比为：

```
SNR_jammed = P_r / (P_n + P_j)     (3-22)
```

干扰功率P_j增加了接收机的总噪声（P_n + P_j），导致信噪比下降。当P_j >> P_n时，信噪比主要由干扰功率决定，目标回波淹没在干扰中。

为简化计算并满足实时仿真需求，本项目将电子对抗等效为一个对探测概率的修正因子η_ECM：

```
P_d_jammed = P_d × η_ECM     (3-23)
```

η_ECM越小，干扰效果越强。例如，η_ECM=0.30表示探测概率降低至原来的30%。

模型中包含了噪声干扰、欺骗干扰、箔条干扰三种典型电子对抗措施（模拟战斗机机载自卫电子对抗系统，如ALQ-131吊舱）。不同干扰类型对不同雷达的影响系数如下表所示：

| 干扰类型 | 对APG-68的影响 | 对N001VE的影响 | 物理原理 |
|---------|--------------|--------------|---------|
| 噪声干扰 | η = 0.50 | η = 0.30 | 在接收频段内注入宽带噪声，提高噪声基底，淹没目标回波 |
| 欺骗干扰 | η = 0.60 | η = 0.50 | 生成虚假目标回波或延迟回波，迷惑雷达信号处理器，产生虚假航迹 |
| 箔条干扰 | 未实现 | η = 0.20 | 抛撒金属箔条（长度约等于雷达波长的一半），形成强反射云团，遮蔽真实目标 |

APG-68因具备更强的ECCM（电子反对抗）能力，受干扰影响更小。友方APG-68当前未实现箔条干扰响应，基于其优秀的抗干扰能力和ECCM技术（频率捷变、杂波图、航迹关联等）。敌方N001VE实现了完整的三种ECM响应。

雷达的ECCM能力通过以下技术实现：频率捷变（Frequency Agility）快速跳频避开干扰频段，APG-68和N001VE均支持；旁瓣抑制（Sidelobe Suppression）降低天线旁瓣增益以减少侧向干扰（APG-68为0.90，N001VE为0.85）；低截获概率（LPI）技术降低发射功率、使用伪随机编码等，使敌方难以探测和干扰（APG-68为0.65，N001VE无此能力）。综合ECCM能力：APG-68为0.82，N001VE为0.70。

电子对抗措施的激活采用威胁驱动激活机制，基于RWR（雷达告警接收机）探测到的威胁等级智能激活。激活概率与威胁等级正相关：威胁等级≥3（被锁定或导弹威胁）时，友方APG-68以80%概率激活ECM，敌方N001VE以90%概率激活（因ECCM能力较弱，更依赖ECM防御）；威胁等级=2（被跟踪）时，友方30%概率、敌方40%概率激活；威胁等级=1（被搜索）时，友方5%概率、敌方10%概率预防性激活；威胁等级=0（无威胁）时不激活ECM。

这种威胁驱动机制符合真实空战中ECM的使用策略：在高威胁情况下立即激活，避免在安全时浪费ECM资源或暴露电子特征。ECM激活后持续5-15秒的均匀分布时间。模型同时考虑了雷达具备的频率捷变能力，设定了抗干扰系数η_resist（APG-68为0.75，N001VE为0.60），反映雷达通过ECCM技术降低干扰影响的能力。

## 3.6 目标跟踪与锁定逻辑

雷达系统采用多阶段工作模式以高效管理探测资源：搜索模式（Search）采用广域扫描，波束宽、扫描范围大，用于发现新目标；跟踪模式（Track，TWS - Track While Scan）集中能量，波束窄、更新率高，用于维持已发现目标的精确航迹；锁定模式（Lock，STT - Single Target Track）波束最窄、更新率最高，为武器系统提供高精度的制导信息。

模式之间的转换由目标距离R（单位：m）和跟踪质量Q_track共同决定。对于友方APG-68雷达，当R ≤ 70 km且Q_track > 0.5时进入LOCK模式，当R ≤ 85 km且Q_track > 0.3时进入TRACK模式，否则保持SEARCH模式。对于敌方N001VE雷达，当R ≤ 45 km且Q_track > 0.6时进入LOCK模式，当R ≤ 70 km且Q_track > 0.3时进入TRACK模式，否则保持SEARCH模式。形式化表示为：

```
Mode(APG-68) = {
    LOCK,    if R ≤ 70 km ∧ Q_track > 0.5
    TRACK,   if R ≤ 85 km ∧ Q_track > 0.3
    SEARCH,  otherwise
}     (3-25a)

Mode(N001VE) = {
    LOCK,    if R ≤ 45 km ∧ Q_track > 0.6
    TRACK,   if R ≤ 70 km ∧ Q_track > 0.3
    SEARCH,  otherwise
}     (3-25b)
```

雷达模式转换需要同时满足距离和质量两个条件：距离条件确保目标在有效工作范围内（APG-68性能更强，锁定距离更远），质量条件确保航迹足够稳定可靠（LOCK模式要求更高的质量）。APG-68对LOCK模式的质量要求更低（0.5 vs 0.6），因为其跟踪精度更高，对航迹稳定性的依赖更小。

跟踪质量Q_track是一个综合指标，其物理含义是目标航迹的稳定性和可信度，由距离因子f_distance、时间因子f_time和机动因子f_maneuver共同决定：

```
Q_track = f_distance × (1.0 - f_time) / f_maneuver     (3-26)
```

距离因子f_distance反映距离对跟踪精度的影响。设R_track为最大跟踪距离（APG-68为85000 m，N001VE为70000 m），则：

```
f_distance = max(0.1, 1.0 - R / R_track)     (3-27)
```

距离越近，回波越强，跟踪越准确，f_distance越大。在最大跟踪距离处，f_distance降至0，但max函数保证最低值为0.1。

时间因子f_time反映航迹的时效性。设Δt为距离上次更新的时间间隔（单位：s），T_update为跟踪更新周期（APG-68为4.0 s，N001VE为5.0 s），则：

```
f_time = min(1.0, Δt / T_update)     (3-28)
```

刚更新时（Δt=0），f_time=0，(1.0-f_time)=1.0，质量最高。随着时间流逝，航迹的可信度下降。超过更新周期时，f_time≥1.0，(1.0-f_time)≤0，质量降至最低。

机动因子f_maneuver反映目标机动对跟踪难度的影响。设φ_roll为目标滚转角（单位：度），则：

```
f_maneuver = {
    1.0 + 0.5 × (|φ_roll| / 90°),  APG-68（最大2.0）
    1.0 + 0.8 × (|φ_roll| / 90°),  N001VE（最大2.5）
}     (3-29)
```

高机动目标（大滚转角）更难跟踪，因为其运动轨迹不可预测，雷达的航迹预测算法难以准确估计其位置。N001VE对机动目标更敏感（系数0.8 vs 0.5），跟踪丢失概率更高。当目标以最大滚转角（90°）机动时，APG-68的f_maneuver达到1.5，N001VE达到1.8，导致Q_track显著下降。

在多目标环境下，雷达需要对不同威胁进行优先级排序。目标优先级P_priority基于距离和跟踪质量综合计算：

```
P_priority = (1.0 / max(R, 1000)) × Q_track     (3-30)
```

距离最近且跟踪质量最高的目标将被优先锁定。这符合威胁评估原则：近距离、高质量航迹的目标构成最大威胁。式中max(R, 1000)避免了除零错误。

为避免因信号起伏导致工作模式在临界状态频繁跳变（抖动），系统要求连续满足转换条件后，才最终确认状态的转换。跟踪质量的动态变化和多目标优先级的计算，是实现"拖曳射击"和"并排射击"等协同战术的核心。在本项目的2v2空战仿真中，实现了拖曳射击（Drag Shoot）和并排射击（Side by Side Shooting）两种典型协同战术。拖曳射击是指长机和僚机采用时间差发射导弹，长机先发射后执行Short Skate机动撤离，僚机在稍后时刻发射并掩护长机，形成连续威胁；并排射击是指长机和僚机保持横向间隔的并排队形，在接近最佳发射距离时同时发射导弹，形成饱和攻击。雷达系统决定了火控系统何时能够提供满足武器发射条件的精确制导信息，并如何在多个威胁目标之间进行高效的火力分配。

## 3.7 RWR与导弹发射集成

### 3.7.1 RWR系统建模

雷达告警接收机（Radar Warning Receiver, RWR）是现代战斗机的重要电子战设备，用于被动探测和识别敌方雷达辐射，为飞行员提供威胁告警。RWR系统将探测到的雷达威胁分为6个等级L_threat：0表示无威胁，1表示搜索模式照射（SEARCH），2表示跟踪模式照射（TRACK，TWS），3表示锁定模式照射（LOCK，STT），4表示检测到导弹发射，5表示检测到导弹制导雷达。威胁等级递增反映了战术威胁的升级：搜索时威胁较低，跟踪时威胁中等，锁定时威胁高且可能即将被导弹攻击，检测到导弹发射或制导雷达时威胁极高或紧急。

RWR不仅提供威胁等级，还能测定威胁源的方位角θ_threat = arctan2(Δx, Δy)，其中(Δx, Δy)为威胁源相对本机的水平位置差（单位：m）。RWR通过测量敌方雷达信号的到达角（Angle of Arrival, AOA），计算威胁源的方位，为飞行员提供威胁的方向信息，辅助战术机动决策。

本模型实现了双向对称的RWR系统，友方和敌方均能探测对方雷达辐射，用于自动触发ECM（见3.5节）、战术机动决策（如Notch机动）和火力分配优化。

### 3.7.2 导弹发射集成检查

为确保导弹发射的战术合理性，本模型实现了完整的雷达-武器集成检查逻辑。导弹发射前需满足以下六个条件：目标在雷达跟踪列表中（target_id ∈ tracked_targets），雷达处于TRACK或LOCK模式（Mode ≥ TRACK），跟踪质量达到最低要求（Q_track ≥ 0.3），目标在最大跟踪距离内（R ≤ R_track），目标不在多普勒盲区（|v_r| > v_threshold），探测概率达到基本要求（P_d ≥ 0.2）。

不同导弹对雷达状态要求不同。R-27ER半主动雷达制导导弹要求发射机雷达持续锁定目标（STT模式）直至导弹命中，雷达需为导弹提供目标照射，导弹通过接收目标反射的雷达波进行制导。AIM-120主动雷达制导导弹只需TWS模式提供中段数据链更新，末段由导弹自主制导，发射后雷达可切换回搜索模式或跟踪其他目标。这些差异体现了不同制导体制对雷达支持的不同需求。

## 3.8 概率性探测机制

为模拟真实雷达探测过程中的随机不确定性，本模型采用概率性探测机制。对于计算得到的综合探测概率P_d，通过与一个[0,1]区间内均匀分布的随机数ξ进行比较，来判定本次扫描是否成功探测到目标：当ξ < P_d时判定为探测成功（Detection = Success），当ξ ≥ P_d时判定为探测失败（Detection = Failure）。

这种机制模拟了真实雷达探测中的信号起伏、噪声波动、杂波闪烁等随机因素。即使探测概率较高（如P_d=0.8），也存在20%的可能性单次扫描失败。这使得对远距离、低RCS或受干扰目标的探测不再是一个确定性的过程，而是需要多次扫描尝试才能建立稳定航迹，这与真实战场环境更为贴近，也为战术仿真增加了更多的不确定性与博弈性。

## 3.9 模型总结与验证

公式(3-1)至(3-30)构成了完整的功能级雷达探测与跟踪模型。该模型建立了从目标参数获取、探测概率计算到雷达状态管理的完整计算链路。模型同时实现APG-68(V)9和N001VE两型雷达，体现第四代与第三代雷达的技术代差。基于真实雷达手册参数，包括探测距离、扫描周期、波束宽度等。涵盖动态RCS、多普勒盲区、地面杂波、RWR、ECM/ECCM等战术要素。通过简化底层物理过程，适合大规模多智能体实时仿真，统一的API接口支持多种战术模板复用。

模型参数与真实雷达手册数据对比验证结果如下：

| 参数 | APG-68手册值 | 模型值 | 误差 | N001VE手册值 | 模型值 | 误差 |

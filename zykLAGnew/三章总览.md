# 论文代码使用说明（按第3/4/5章组织）

本工程在原有代码基础上新增 `chapters/` 目录，提供按论文第3章/第4章/第5章的**复现入口**与**分章使用说明**。
核心代码仍位于仓库根目录的模块（如 `Tactical_Rule_Template/`、`envs/`、`algorithms/`、`runner/`、`scripts/`）。

---

## 第一部分：三章总览矩阵

| 章节目标 | 对应脚本（入口） | 核心配置（映射） | 输出产物（落盘位置） | 验证方式 |
|---|---|---|---|---|
| 第三章：验证“战术模板语言/库 + 执行器”可用 | `chapters/ch03_templates/run_demo.py` | 默认使用 `envs/JSBSim/configs/2v2/ShootMissile/HierarchySelfplay.yaml` | `outputs/ch03/*.acmi`（TacView轨迹）+ 终端日志 | TacView 打开 `.acmi`，观察模板阶段切换与高层指令是否符合预期 |
| 第四章：复现 1v1 与 2v2 的（自博弈）训练流程 | `chapters/ch04_popt/train_1v1_shoot_selfplay.py` / `train_2v2_shoot_selfplay.py` | 1v1：`envs/JSBSim/configs/1v1/ShootMissile/HierarchySelfplay.yaml`；2v2：`envs/JSBSim/configs/2v2/ShootMissile/HierarchySelfplay.yaml` | 训练模型：`scripts/results/<env>/<scenario>/<algo>/<exp>/run*/actor_latest.pt`；渲染轨迹：同目录下 `render/*.acmi` | 训练：loss/回报打印或 wandb；渲染：TacView 打开 `.acmi` 复盘 |
| 第五章：复现协同训练入口（CC-IVB/CC-SVB 与 CCC塑形的开关） | `chapters/ch05_ccivb/train_ccivb.py`（开） / `train_baseline.py`（关） | 环境：`envs/JSBSim/configs/2v2/ShootMissile/HierarchySelfplay.yaml`；开关：环境变量 `USE_CC_SVB`、`USE_CCC_RSHAPE` | `scripts/results/MultipleCombat/2v2/ShootMissile/HybridRL/<EXP_NAME>/run*/actor_latest.pt` | 查看训练输出中的 `[CCC] rate=...`；对比两次运行的日志（见 `compare_logs.py`） |

## 运行前置（一次性）

1. 安装依赖（示例，详见根目录 `README.md`）：
   - Python 3.8 + Conda 环境
   - `pip install torch pymap3d jsbsim==1.1.6 geographiclib gym==0.20.0 wandb icecream setproctitle`
2. 初始化子模块（若使用 git 克隆）：`git submodule init && git submodule update`

> 注：本说明默认在仓库根目录执行命令，或直接运行 `chapters/` 下的入口脚本。
